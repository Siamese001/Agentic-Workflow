================================================================================
                        KEY INTERACTIONS
================================================================================

1. Canon Validator → Protocol 1 & 2:
   validate_python_syntax() → AST check → PASS/FAIL
   execute_in_sandbox() → Docker test → PASS/FAIL

2. Resume Engine → Protocol 3 & 4:
   firewall.scan_input(job_desc) → Injection check → PASS/FAIL
   fact_checker.validate_skills(draft) → Hallucination check → PASS/FAIL

3. Outreach Engine → Protocol 5:
   register_process() → PID registration
   log_action("SEND_EMAIL") → Activity logging
   DeadManSwitch.monitor() → Kill if excessive actions

4. All Engines → L5 MEMemory:
