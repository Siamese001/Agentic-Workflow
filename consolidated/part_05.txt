**Legend (5-Level Gradation)**  

* **🟦 Level 4 — Self-Evolving System**    
  Autonomously creates or discovers tools (MCP discovery + meta-learning).  
* **🟩 Level 3 — Collaborative Multi-Agent System**    
  Agents coordinate via async conductor and A2A messaging.  
* **🟨 Level 2 — Strategic Problem-Solver**    
  Plans multi-step goals with context engineering and branch selection.  
* **🟧 Level 1 — Connected Problem-Solver**    
  Reasoning engine linked to external tools but not adaptive.  
* **🟥 Level 0 — Isolated Reasoner**    
  Static LLM with no world feedback.  
* **🟩 (Mature)** – Support stacks (QA, Safety, Telemetry) function as adaptive subsystems.

     ╰───────────────────────────────────────────────────────────────────────╯

💬 **101-Level Breakdown:**

* **RAGSTACK (Retrieval-Augmented Generation):**  
  This is your *research department*.  
  It searches both stored documents and online sources using techniques like **BM25**, a mathematical way of ranking relevance.  
  BM25 measures:  
  - How often a word appears in a document (*term frequency*).  
  - How unique that word is across all documents (*inverse document frequency*).  
  The result is a ranked list of the *most contextually relevant evidence*.  
  Combined with **vector search** (semantic similarity) and **HyDE** (Hypothetical Document Expansion), it ensures both accuracy and creativity — grounding content in fact *while suggesting new angles.*

* **PROMPTSTACK (Context Engineering):**  
  Frames the retrieved data into structured reasoning — like turning raw notes into an executive summary.  
  It controls *tone, formality, and voice*, ensuring the résumé feels polished and human.  

* **MCP BRIDGE (Model Context Protocol):**  
  Think of this as your **Chief of Staff for AI tools**.  
  It can discover, request, or coordinate external skills (like a grammar-check agent, data summarizer, or recruiter insight engine) without pre-programming.  
  This makes the workflow modular and adaptive — every run can improve.

💬 **Executive Learning Question:**  
Why does parallelism matter?  
Because the world doesn’t wait for sequential thinkers.  
Parallel retrieval, planning, and prompting mirror real executive cognition: *multiple perspectives, one synthesis.*

│      ├─ Emits → {bias_score, neutral_text}.                                                │
│      │                                                                                     │
│      │  Function → Balances emotional intensity and inclusivity of expression.             │
│      │  Resume Effect → Keeps content **persuasive yet professional** — confident          │
│      │                     without arrogance, assertive without aggression.               │

│      │                     but still credible to recruiters and executives.               │

def conceptual_node_map() -> Dict[str, ConceptualNode]:
    """Return a lookup dictionary for conceptual nodes by name."""

    return {node.name: node for node in CONCEPTUAL_DAG}


def all_concrete_nodes() -> Set[str]:
    """Return the flattened set of concrete node names covered by the spec."""

    return {
        concrete
        for node in CONCEPTUAL_DAG
        for concrete in node.concrete_nodes
    }


def iter_concrete_nodes(node_names: Iterable[str]) -> Iterable[str]:
    """Iterate over all concrete nodes for the given conceptual node names."""

    lookup = conceptual_node_map()
    for name in node_names:
        conceptual = lookup.get(name)
        if not conceptual:
            continue
        yield from conceptual.concrete_nodes
