                               GIT — CONSOLIDATED VISUAL MODEL
══════════════════════════════════════════════════════════════════════════════════════════════════════

REMOTE (server)                                  LOCAL REPOSITORY
──────────────────────────────────────────────────────────────────────────────────────────────────────

origin/main
    │
    ▼
                    main
                     │
                     ▼
A ─── B ─── C ─── D ─── E
                │
                ▼
             feature
                ▲
                │
              HEAD


LEGEND
──────
A–E        = commits (snapshots of the project)
main       = branch (just a movable pointer)
feature    = another branch pointer
HEAD       = your current working position
origin/*   = remote branch on server


══════════════════════════════════════════════════════════════════════════════════════════════════════
1️⃣ MAKING A COMMIT
══════════════════════════════════════════════════════════════════════════════════════════════════════

You are on feature. You commit.

A ─── B ─── C ─── D ─── E
                │
                ▼
             feature
                │
                ▼
                F
                ▲
                │
              HEAD

✔ A commit moves the current branch forward.
✔ HEAD always follows the branch.


══════════════════════════════════════════════════════════════════════════════════════════════════════
2️⃣ DETACHED HEAD
══════════════════════════════════════════════════════════════════════════════════════════════════════

You checkout a specific commit (C):

A ─── B ─── C ─── D ─── E
            ▲
            │
          HEAD

main    → E
feature → F

⚠ You are NOT on a branch.
⚠ New commits will not belong to any branch.

If you commit now:

A ─── B ─── C ─── D ─── E
            │
            ▼
            X
            ▲
            │
          HEAD

Commit X is "orphaned" unless you create a branch.


══════════════════════════════════════════════════════════════════════════════════════════════════════
3️⃣ MERGE (Preserves Branch History)
══════════════════════════════════════════════════════════════════════════════════════════════════════

Before merge:

A ─── B ─── C ─── D         (feature)
        │
        ▼
        E ─── F             (main)

After: git merge feature (while on main)

A ─── B ─── C ─── D
        │         │
        ▼         ▼
        E ─── F ─── M
                     ▲
                     │
                    main

M = merge commit (2 parents)

✔ History preserved
✔ No commits rewritten
✔ Safe for shared branches


══════════════════════════════════════════════════════════════════════════════════════════════════════
4️⃣ REBASE (Rewrites History)
══════════════════════════════════════════════════════════════════════════════════════════════════════

Before:

A ─── B ─── C ─── D         (feature)
        │
        ▼
        E ─── F             (main)

git rebase main (while on feature)

A ─── B ─── C ─── E ─── F ─── D'
                                      ▲
                                      │
                                   feature

D becomes D' (new hash)

✔ Linear history
⚠ Commit hashes change
⚠ Do not rebase shared branches


══════════════════════════════════════════════════════════════════════════════════════════════════════
5️⃣ SQUASH (Combine Commits)
══════════════════════════════════════════════════════════════════════════════════════════════════════

Before interactive rebase:

A ─── B ─── C ─── D ─── E   (feature)

After squash:

A ─── B ─── C ─── S

S = combined commit of D+E

✔ Cleaner history
⚠ Old commits replaced (new hash)


══════════════════════════════════════════════════════════════════════════════════════════════════════
6️⃣ FORCE PUSH (After Rebase)
══════════════════════════════════════════════════════════════════════════════════════════════════════

Remote before:

origin/feature → D

Local after rebase:

feature → D'

Remote still points to D.

To update:

git push --force

origin/feature → D'

⚠ Rewrites remote history
⚠ Dangerous if others pulled D


══════════════════════════════════════════════════════════════════════════════════════════════════════
7️⃣ PULL (Two Modes)
══════════════════════════════════════════════════════════════════════════════════════════════════════

git pull (merge mode):

origin/main → F
main → E

Result:

E ─── F ─── M

git pull --rebase:

Replays your local commits on top of F (no merge commit).


══════════════════════════════════════════════════════════════════════════════════════════════════════
CORE CONCEPT BOX
══════════════════════════════════════════════════════════════════════════════════════════════════════

Commit  = Snapshot
Branch  = Movable pointer
HEAD    = Your current position
Merge   = Combine histories (safe)
Rebase  = Replay commits (rewrite history)
Squash  = Combine commits
Detached= On commit, not branch
Force   = Overwrite remote history

BEGINNER SAFE RULES
══════════════════════════════════════════════════════════════════════════════════════════════════════

✔ Merge shared branches
✔ Rebase only your own feature branches
✔ Never force-push shared main
