### How to generate

Minimum manual process (until a generator lands in a future phase):

1. Run `python tools/adg/three_bucket_gap_report.py` to regenerate the JSON.
2. Run each strict gate listed in §2 — capture exit code + any violation output.
3. Copy this template to `three-bucket-soak-<YYYY-Www>.md`.
4. Fill in §1–§6 from the JSON + gate runs.
5. Update the counter table in §4 by reading the previous week's final counter value.
6. Commit. Pre-commit will run the gates in §2 again as a final cross-check.
