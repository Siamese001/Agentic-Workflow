# Windsurf Recovered Plans Archive

This directory preserves recovered Windsurf-era plan and report artifacts for
search, audit, and forensics.

These files are not active governance inputs, not current plan SSOT files, and
should not be treated as registered execution plans. Active plans live under the
repo's governed plan locations and remain subject to the normal plan lifecycle.

Contents:

- `manifest.csv` - recovery manifest from the source archive.
- `manifest_enriched.csv` - recovery manifest with additional date metadata.
- `windsurf_plans/` - recovered Windsurf plan files.
- `docs_reports_plans/` - recovered historical report/plan artifacts.
