PURPOSE
------------------------------------------------------------------------------------------------------------------------
Implement L6 6A ingest and normalization for completed-run exhaust only.

This child answers one question:
"Can the completed run's sealed exhaust be collected, lineage-bound, normalized, and made eval-ready without mutating live state?"

PIPELINE REQUIREMENTS
------------------------------------------------------------------------------------------------------------------------
I1. Receive completed-run marker
- Refuse live/in-flight runs.
- Require Exit disposition or explicit ingest repair fixture marker.
- Bind runtime boundary timestamp.

I2. Collect source refs
- Pull only sealed runtime artifacts and traces.
- Do not ask live layers to recompute or mutate.
- Preserve raw refs before normalization.

I3. Validate lineage keys
- Check trace_id, span_id, run_id, request_id, route_id, step_id, attempt_id where applicable.
- Check policy_hash, blueprint_hash, prompt_hash, replay_key.
- Identify missing trace link, orphan artifact, unsealed span, impossible stage order, duplicate run identity.

I4. Build StageMap
- Map U0 -> L1 -> L0 -> C0/PA/L3/L2 -> Exit -> UWG where present.
- Mark missing optional stages as NOT_APPLICABLE, not missing.
- Mark required missing stages as gap.

I5. Build ArtifactInventory
- Inventory generated files, payloads, tool/model receipts, stdout/stderr, proposed diffs, commit receipts.
- Preserve hashes and lineage.
- Quarantine unsafe payload refs.

I6. Normalize records
- Convert provider, trace, tool, model, token, latency, cost, retry, route, policy, HITL, exit, and UWG formats into canonical records.
- Preserve original raw refs; never summarize away machine lineage.

I7. Stratify run outcome
- normal_success, degraded_success, safe_abstain, denied_unsafe_request, rerouted_request, hitl_escalated,
  tool_failure, model_failure, grounding_failure, policy_failure, replay_failure, schema_failure, unresolved_unknown.

FAILURE MODES
------------------------------------------------------------------------------------------------------------------------
- LIVE_RUN_NOT_CLOSED -> reject ingest.
- EXIT_DISPOSITION_MISSING -> HOLD_FOR_MISSING_EVIDENCE.
- TRACE_LINK_MISSING -> gap report, not fabricated linkage.
- ORPHAN_ARTIFACT -> gap report and eval-readiness penalty.
- IMPOSSIBLE_STAGE_ORDER -> mark non-evaluable until telemetry repair.
- POLICY_HASH_MISMATCH -> governance eval candidate.
- REPLAY_KEY_MISSING -> non-evaluable for replay-dependent analyses.
- UNKNOWN_PROVIDER_FALLBACK -> trajectory/governance eval candidate.

TEST REQUIREMENTS
------------------------------------------------------------------------------------------------------------------------
Tests must fail if:
- L6 ingests an in-flight run as completed.
- Missing evidence is filled by inference.
- Raw traces are rewritten instead of referenced.
- Lineage is summarized away.
- Optional stage absence is treated as required failure.
- Required stage absence is silently ignored.
- Orphan artifacts are accepted without gap report.
- Normalized records omit replay_key, policy_hash, or trace lineage.
