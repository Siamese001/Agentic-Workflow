OBSERVER LAW
------------------------------------------------------------------------------------------------------------------------
L6 may read:
- runtime traces, artifacts, prompts, evidence contracts, route contracts, HITL dispositions, Exit decisions, commit receipts,
  policy outcomes, eval outputs, and sealed runtime exhaust.

L6 must not:
- write to L4.
- publish to BUS U.
- mutate prompt, policy, rubric, route, threshold, registry, retrieval profile, cache, or memory.
- rescue the current run.
- alter live Exit/HITL/UWG decisions.
- regrade current disposition as live authority.
- feed back into the runtime path before the run is complete.

READINESS DECISION RULES
------------------------------------------------------------------------------------------------------------------------
READY_FOR_6B:
- Trace completeness sufficient.
- Artifacts integrity verified.
- replay_key present when replay-dependent evals apply.
- policy_hash, route contract, terminal status, source lineage present.
- Evaluator inputs available.

PARTIAL_BUT_SCORABLE:
- Some fields missing, but at least one bounded evaluation dimension can be scored without inference.
- Missing dimensions must be marked UNKNOWN or NOT_EVALUABLE.
- Partial scoring cannot promote learning alone.

HOLD_FOR_MISSING_EVIDENCE:
- Missing fields likely recoverable via telemetry repair or delayed exhaust arrival.
- Hold does not mutate runtime.
- Hold cannot feed RCA/proposal until resolved or explicitly downgraded.

NON_EVALUABLE_PACKET:
- Required lineage, trace, policy, or terminal facts are missing and cannot be safely reconstructed.
- Exclude from learning.
- Retain gap report for observability repair.

VIOLATION RESPONSE
------------------------------------------------------------------------------------------------------------------------
If L6 attempts a forbidden write or live mutation:
- stop ingest lane.
- freeze suspect packet.
- classify sovereignty breach.
- emit L6_OBSERVER_FAIL.
- create denied write attempt record.
- require UWG/L4 audit review.
- block downstream 6B/6C/6D use of the suspect packet.

TEST REQUIREMENTS
------------------------------------------------------------------------------------------------------------------------
Tests must fail if:
- L6 code path has write credentials to L4.
- L6 publishes BUS U before UWG/L4 materialization.
- L6 mutates prompt/policy/rubric thresholds directly.
- L6 starts before Exit disposition exists.
- Missing replay_key is silently ignored for replay-dependent eval.
- Non-evaluable packet is admitted to RCA or proposal drafting.
- Partial scoring is promoted as complete evaluation.
