APPROVAL, UWG HANDOFF, AND FUTURE-RUN RULES
------------------------------------------------------------------------------------------------------------------------
APPROVE only if:
- completed 6B eval exists and is fresh.
- RCA/pattern exists.
- gauntlet receipt passes.
- calibration freshness is acceptable.
- no partial bypass.
- signer authority verified.
- rollback plan verified.
- blast radius accepted.

L6 may create a PromotionUWGRequestPackage only after ApprovalDecisionRecord = APPROVE.

The package must include:
- proposal_id, approval_decision_id, gauntlet_receipt, content_hash, signer_identity, policy_hash, target_surface,
  blast_radius, rollback_plan, version bump, alias swap plan, cache/read-surface refresh plan.

Hard law:
- UWG commits.
- L4 stores.
- L6 does not write.
- BUS U activation is future-run only after UWG receipt.

Future-run publish:
- Activation at next run_start only.
- No completed-run mutation.
- No current-run rescue.
- No retroactive regrade.
- No hidden threshold change.
- No BUS U publish without UWG receipt.

TEST REQUIREMENTS
------------------------------------------------------------------------------------------------------------------------
Tests must fail if:
- proposal is approved without gauntlet.
- stale eval is used on write.
- promotion lacks rollback.
- L6 writes to L4 directly.
- BUS U publish occurs before UWG receipt.
- activation affects current run.
- content_hash differs between approved packet and UWG package.
- no ledger proof refs are stored after UWG receipt.
