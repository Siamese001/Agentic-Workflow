PHASE 2 WORKSTEPS
------------------------------------------------------------------------------------------------------------------------
C0.5.1 Verify shaped set integrity
- Confirm shaped_set_hash.
- Confirm original evidence refs exist.
- Confirm all required strata are present or explicitly empty.
- Confirm no excluded evidence is accidentally packable.

C0.5.2 Verify citation anchors
- Check span_ref, line_range, timestamp_range, row_key, file path, symbol, or clause anchor as required by support_target.
- Mark no_citation_anchor as weak or unfit for exact quote.
- Build CitationSupportMap.

C0.5.3 Verify freshness
- Compare source timestamps, versions, commit refs, snapshot IDs, and policy effective dates to freshness_class.
- Do not silently use stale evidence as current evidence.

C0.5.4 Verify authority and scope
- Confirm source authority class meets support_target profile.
- Confirm ACL, tenant, region, and data class remain within RouteContract.
- Confirm origin labels mark retrieved content as data.

C0.5.5 Verify contradiction handling
- Surface material contradictions.
- Map contradicting evidence to contradiction_manifest.
- Do not hide docs-vs-code, design-vs-runtime, or old-vs-new source conflicts.

C0.5.6 Score support
- Apply threshold profile.
- Produce SupportScoreBreakdown.
- Record confidence band.
- Distinguish direct support from downstream inference risk.

C0.5.7 Decide evidence status
- Emit PASS, WEAK_WITH_CAVEATS, CONFLICTED, EMPTY, or BLOCKED.
- Record why.
- This is evidence status, not current-run disposition.

C0.5.8 Emit FinalEvidenceContract
- Include packable refs for Prompt Assembly.
- Include unfit and excluded refs for audit.
- Include gap report and refinement eligibility.
- Hash contract deterministically.

GATES AND FAILURE MODES
------------------------------------------------------------------------------------------------------------------------
Required gates:
- shaped_set_integrity_gate
- citation_anchor_gate
- support_threshold_gate
- freshness_gate
- source_authority_gate
- acl_contract_gate
- contradiction_manifest_gate
- packability_gate
- contract_hash_gate

Failure behavior:
- No shaped evidence -> evidence_status = EMPTY.
- ACL violation -> evidence_status = BLOCKED or exclude offending evidence if non-material.
- Material contradiction -> evidence_status = CONFLICTED unless adequately resolved by source authority and freshness.
- Weak citations -> WEAK_WITH_CAVEATS for summary, BLOCKED/WEAK for quote depending profile.
- Stale evidence for current claim -> WEAK_WITH_CAVEATS or CONFLICTED if newer contrary evidence exists.
