C0.3 GRAPH RAG / GRAPH EXPANSION, ZERO-LOSS OVERWRITE
Example ask:
"Find the current pet policy in Amit's lease and cite the exact clause."

CORE DISTINCTION
================

C0.1 plans the search.
C0.2 pulls candidate chunks and hydrates metadata.
C0.3 expands bounded graph context only when graph is enabled.
C0.3 asks: "What relationships around these candidates matter?"

C0.2 = CandidateEvidencePool.
C0.3 = GraphExpandedEvidencePool.
C0.3 does not fetch new unplanned sources.
C0.3 does not answer.
C0.3 does not assemble prompts.
C0.3 does not rerank into final strata.
C0.3 does not write L4.

GUARDRAILS
==========

┌──────────────────────────────────────────────────────────────────────────────┐
│ C0.3 GRAPH GUARDRAILS                                                        │
│                                                                              │
│ Expand only from C0.2 candidates.                                             │
│ Expand only if graph was planned/enabled.                                     │
│ Enforce max_hops.                                                             │
│ Enforce ACL, tenant, source scope, data class, freshness.                     │
│ Use graph projection/GraphDB adapter, not ad hoc SQLite walk.                 │
│ Keep contradictions, exceptions, supersession, and stale signs.               │
│ Keep rejected neighbors with reasons.                                         │
│ Do not fetch unrelated sources.                                               │
│ Do not turn graph neighbors into trusted evidence automatically.              │
│ Do not answer.                                                               │
│ Do not assemble prompt slots.                                                 │
│ Do not decide final strata.                                                   │
│ Do not write L4.                                                             │
│                                                                              │
│ If graph unavailable:                                                         │
│ emit graph_gap or graph_skipped_receipt and pass candidates to C0.4.          │
