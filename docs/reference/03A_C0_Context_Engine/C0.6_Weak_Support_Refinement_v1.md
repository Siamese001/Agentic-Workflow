C0.6 WEAK SUPPORT REFINEMENT, ZERO-LOSS OVERWRITE
Example ask:
"Find the current pet policy in Amit's lease and cite the exact clause."

CORE DISTINCTION
================

C0.1 plans the search.
C0.2 pulls candidate chunks and hydrates metadata.
C0.3 expands bounded graph relationships.
C0.4 shapes, reranks, trims, and stratifies evidence.
C0.5 verifies support and emits exactly one FinalEvidenceContract.
C0.6 runs one controlled refinement loop only when C0.5 support is weak, empty, conflicted, or blocked in a remediable way.

C0.5 = FinalEvidenceContract.
C0.6 = refined evidence attempt OR final gap report.

C0.6 asks:
"Can support improve inside the same authority boundary?"

C0.6 does not override L0.
C0.6 does not broaden outside allowed sources.
C0.6 does not bypass ACL.
C0.6 does not invent evidence.
C0.6 does not answer.
C0.6 does not assemble prompts.
C0.6 does not execute tools.
C0.6 does not write L4.
C0.6 does not loop forever.

C0.6 REFINEMENT DECISION
========================

┌──────────────────────────────────────────────────────────────────────────────┐
│ C0.6.1 CLASSIFY THE GAP                                                       │
│                                                                              │
│ Gap type: WEAK                                                                │
│ - evidence exists but is thin or incomplete                                   │
│ - example: dense hit found "tenant obligations" but no exact pet clause       │
│                                                                              │
│ Gap type: WEAK_WITH_CAVEATS                                                   │
│ - evidence is usable only with explicit caveats                               │
│ - example: pet clause found, but lease addendum status unclear                │
│                                                                              │
│ Gap type: EMPTY                                                               │
│ - no usable candidate evidence found                                          │
│ - example: no pet/animal clause in current lease docs                         │
│                                                                              │
│ Gap type: CONFLICTED                                                          │
│ - credible current sources disagree                                           │
│ - example: lease says no pets, current addendum says one pet allowed          │
│                                                                              │
│ Gap type: BLOCKED                                                             │
│ - ACL/policy/source restriction blocks use                                    │
│ - example: lease exists but user lacks ACL for that source                    │
│                                                                              │
│ Only remediable gaps may refine.                                              │
│ Non-remediable gaps stop with final gap report.                               │
└──────────────────────────────────────┬───────────────────────────────────────┘
                                       ▼
┌──────────────────────────────────────────────────────────────────────────────┐
│ C0.6.2 DECIDE SAFE REFINEMENT AVAILABLE?                                      │
│                                                                              │
│ Safe refinement = YES when:                                                   │
│ - budget remains                                                              │
│ - max_refine_attempts not exhausted                                           │
│ - source scope remains the same                                               │
│ - ACL remains enforceable                                                     │
│ - query can be improved without new authority                                 │
│ - missing evidence may exist in allowed retrieval surfaces                    │
│                                                                              │
│ Safe refinement = NO when:                                                    │
│ - L0 did not allow more attempts                                              │
│ - needed source is outside allowed_sources                                    │
│ - ACL blocks source                                                           │
│ - issue requires user clarification                                           │
│ - support target cannot be met                                                │
│ - source is missing from retrieval surface                                    │
│ - conflict cannot be resolved inside same authority                           │
└──────────────────────────────────────┬───────────────────────────────────────┘
                                       ▼
