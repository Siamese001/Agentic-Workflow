PHASE 2 WORKSTEPS
------------------------------------------------------------------------------------------------------------------------
C0.0.1 Receive and freeze inputs
- Bind request_id, route_id, replay_key, policy_hash, blueprint_hash, support_target.
- Refuse implicit source expansion or instruction-as-data framing.
- Emit input_freeze_receipt.

C0.0.2 Verify route grants C0 retrieval
- Confirm route_grounding_required == true.
- Confirm RouteContract names C0 as the evidence authority for this route.
- On miss, emit blocked_reason = grounding_not_required or route_disallows_retrieval.

C0.0.3 Verify scope legality
- Apply tenant, ACL, region, data class ceilings.
- Compute allowed_source_classes by intersecting RouteContract allowed_sources with L5 origin-trust manifest and tenant policy.
- On illegal scope, emit blocked_reason = source_scope_illegal or blocked_data_class.

C0.0.4 Set evidence standard
- Map support_target to evidence_standard:
    EXACT_QUOTE, POLICY_CLAUSE, CODE_LOCATION, INCIDENT_EVIDENCE -> strict
    REGULATED / compliance / safety-impact -> regulated
    everything else -> standard
- Strict / regulated standards inherit stricter sparse + metadata requirements downstream.

C0.0.5 Verify budget floor
- Confirm latency_ms, token_budget, and cost_budget are large enough for one bounded retrieval pass.
- On miss, emit blocked_reason = budget_floor_failed.

C0.0.6 Emit deterministic preflight
- Normalize field order. Hash stable fields. Emit preflight_manifest_hash and replay_metadata.
- Handoff to C0.1.

HARD NO
- No retrieval if route does not require grounding.
- No retrieval if source scope is illegal / blocked.
- No route change from inside C0.
- No silent eligibility upgrades. Eligibility is binary plus reason code.
