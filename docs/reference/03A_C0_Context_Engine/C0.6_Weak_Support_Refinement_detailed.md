PHASE 2 WORKSTEPS
------------------------------------------------------------------------------------------------------------------------
C0.6.1 Inspect FinalEvidenceContract
- Read evidence_status, gap_report, citation map, contradiction manifest, support score breakdown.
- Classify weak support cause.
- Do not override C0.5 status.

C0.6.2 Check refinement eligibility
- Confirm max_refine_attempts remains.
- Confirm budget remains.
- Confirm route scope permits additional C0 pass.
- Confirm weak support is recoverable.
- Confirm refinement does not require L3, HITL, external action, or new authority.

C0.6.3 Select bounded strategy
Allowed strategies:
- query_rewrite: improve terms, phrases, synonyms, IDs, symbols, dates.
- broaden_within_scope: loosen metadata/time/parent context/top_k/graph bounds inside ceilings.
- decompose_evidence_need: split query into support subtargets while preserving original route.
- stop_with_gap_report: no safe refinement available.

C0.6.4 Emit re-entry input
- For query or scope changes, emit refined C0RetrievalPlanInput for C0.1.
- For shaping-only changes, emit C0.4 re-entry input only when no new fetch is needed.
- For verification-only changes, emit C0.5 re-entry input only when the issue is scoring/contract metadata.
- Hash re-entry input.

C0.6.5 Record attempt ledger
- Increment attempts_used.
- Reserve budget for the re-entry path.
- Emit RefinementAttemptLedger.

C0.6.6 Stop safely
- If not eligible, emit NoMoreRefinementReport.
- Keep final evidence status weak/empty/conflicted/blocked.
- Provide non-authoritative recommendation hint only.
