C0.0 PREFLIGHT / GROUNDING ELIGIBILITY, ZERO-LOSS OVERWRITE
Example ask:
"Find the current pet policy in Amit's lease and cite the exact clause."

CORE DISTINCTION
================

C0.0 checks whether C0 is allowed to run at all.
C0.1 plans the search only after C0.0 passes.
C0.2 pulls candidate chunks only after C0.1 plans.
C0.3 expands graph only if planned/enabled.
C0.4 shapes evidence.
C0.5 verifies support.
C0.6 refines only if support is weak and refinement is safe.
C0.7 proves the C0 path.

C0.0 = C0PreflightStatus.

C0.0 asks:
"Is C0 allowed to ground this request?"

C0.0 does not plan retrieval lanes.
C0.0 does not fetch chunks.
C0.0 does not run dense/BM25/metadata search.
C0.0 does not graph expand.
C0.0 does not shape or rerank.
C0.0 does not verify final support.
C0.0 does not refine weak support.
C0.0 does not answer.
C0.0 does not assemble prompts.
C0.0 does not execute tools.
C0.0 does not write L4.
