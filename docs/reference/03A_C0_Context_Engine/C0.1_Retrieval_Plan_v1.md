C0.1 RETRIEVAL PLAN, ZERO-LOSS OVERWRITE
Example ask:
"Find the current pet policy in Amit's lease and cite the exact clause."

CORE DISTINCTION
================

L1 tells C0 what evidence is needed.
L0 tells C0 whether it is allowed to search, where it may search, and under what limits.
C0.1 turns both into a RetrievalPlan.

L1 = semantic evidence need, not authority.
L0 = retrieval authority and bounds.
C0.1 = retrieval strategy only.
C0.2 = actual fetch later.

MERGE AND GUARDRAILS
====================

┌──────────────────────────────────────────────────────────────────────────────┐
│ C0.1 MERGE + PLAN RULES                                                      │
│                                                                              │
│ dedupe key: source_id + version + chunk_id + clause/span                     │
│ preserve lane provenance:                                                    │
│ - dense hit: semantically about lease pet rules                               │
│ - BM25 hit: literally contains pet / animal / fee / deposit                  │
│ - metadata hit: current lease, Amit household, citeable clause                │
│                                                                              │
│ exact quote rule:                                                            │
│ - dense-only match is NOT enough                                              │
│ - must have BM25 or metadata-supported exact clause                           │
│ - must preserve citation anchor                                               │
│                                                                              │
│ authority rule:                                                              │
│ - L1 can suggest "lease pet policy"                                          │
│ - only L0 can authorize "search lease_docs"                                  │
│ - C0 cannot broaden to emails, web, old leases, or unrelated docs             │
│ - C0 cannot override ACL, freshness, or source scope                          │
│                                                                              │
│ contradiction rule:                                                          │
│ - if one clause says "no pets" and another says "service animals excepted"   │
│   keep both for C0.4, do not hide conflict                                    │
