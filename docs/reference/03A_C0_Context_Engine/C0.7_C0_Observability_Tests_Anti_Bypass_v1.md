C0.7 OBSERVABILITY / TESTS / ANTI-BYPASS, ZERO-LOSS OVERWRITE
Example ask:
"Find the current pet policy in Amit's lease and cite the exact clause."

CORE DISTINCTION
================

C0.1 plans the search.
C0.2 pulls candidate chunks and hydrates metadata.
C0.3 expands bounded graph relationships.
C0.4 shapes, reranks, trims, and stratifies evidence.
C0.5 verifies support and emits exactly one FinalEvidenceContract.
C0.6 runs one controlled refinement loop only when support is weak and refinement is safe.
C0.7 proves the C0 path was observable, replayable, bounded, and not bypassed.

C0.7 = C0 receipts, spans, proof hooks, and anti-bypass checks.

C0.7 asks:
"Can we prove C0 behaved exactly as claimed?"

C0.7 does not retrieve evidence.
C0.7 does not improve weak support.
C0.7 does not answer.
C0.7 does not assemble prompts.
C0.7 does not execute tools.
C0.7 does not emit FinalEvidenceContract.
C0.7 does not write L4.

ANTI-BYPASS CHECKS
==================

┌──────────────────────────────────────────────────────────────────────────────┐
│ C0.7.3 VERIFY NO-BYPASS INVARIANTS                                            │
│                                                                              │
│ Check 1: No C0 without L0 authority                                           │
│ - C0 must have a RouteContract                                                │
│ - grounding_required must be true for grounded routes                         │
│ - source scope must come from L0                                              │
│                                                                              │
│ Check 2: No fetch without C0.1 plan                                           │
│ - every C0.2 fetch lane must match RetrievalPlan                              │
│ - no unplanned web/email/file source                                          │
│ - no extra graph expansion outside allowed edge types                         │
│                                                                              │
│ Check 3: No answer generation inside C0                                       │
│ - C0 outputs contracts, pools, receipts, gap reports                          │
│ - no final_answer field                                                       │
│ - no model_output as final prose                                              │
│                                                                              │
│ Check 4: No Prompt Assembly behavior inside C0                                │
│ - C0 may estimate packability                                                 │
│ - C0 may not build provider-ready prompt slots                                │
│ - no PromptEnvelope emitted                                                   │
│                                                                              │
│ Check 5: No L2 execution inside C0                                            │
│ - no tool execution                                                           │
│ - no provider call                                                            │
│ - no script execution                                                         │
│ - no StateDiffCandidate                                                       │
│                                                                              │
│ Check 6: No L4 mutation                                                       │
│ - no direct write                                                             │
│ - no index rebuild                                                            │
│ - no cache promotion                                                          │
│ - no memory update                                                            │
│                                                                              │
│ Check 7: No scope widening                                                    │
│ - C0.6 refinement must stay inside L0 allowed_sources                         │
│ - ACL/freshness/data boundaries must not widen                                │
│                                                                              │
│ Output: c0_anti_bypass_receipt                                                │
└──────────────────────────────────────┬───────────────────────────────────────┘
