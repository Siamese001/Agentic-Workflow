C0.4 SHAPE / RERANK / STRATIFY, ZERO-LOSS OVERWRITE
Example ask:
"Find the current pet policy in Amit's lease and cite the exact clause."

CORE DISTINCTION
================

C0.1 plans the search.
C0.2 pulls candidate chunks and hydrates metadata.
C0.3 expands bounded graph relationships.
C0.4 shapes the evidence set into useful strata.

C0.3 = GraphExpandedEvidencePool.
C0.4 = ShapedEvidenceSet.
C0.4 asks: "What should be must-use, supporting, contradiction, background, or excluded?"

C0.4 does not fetch new chunks.
C0.4 does not broaden the source scope.
C0.4 does not answer.
C0.4 does not assemble prompts.
C0.4 does not issue the final evidence contract.
C0.4 does not write L4.
