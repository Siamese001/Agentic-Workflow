OBJECTIVE
------------------------------------------------------------------------------------------------------------------------
Close the cross-child certification gap in 00A by giving L5 a single typed
artifact (L5GovernanceContext) whose deterministic digest must match across
every L5 certifier that touches a packet. Mismatch is fail-closed with a
sealed L5_NOT_CERTIFIED certification evidence record.

This file exists because, prior to its authoring, the 00A children each
defined their own certification surface (safety, authority, origin, HITL,
egress, replay/audit, static governance) but no file owned the rule that
all certifiers must be certifying the SAME governed object. The L2 RCA
(see 04.5a) showed that runtime guarantees which depend on two or more
sibling children agreeing on a resolved context can silently disagree
unless an explicit cross-child invariant file owns the binding.

CRITICAL BOUNDARY
------------------------------------------------------------------------------------------------------------------------
This is a CERTIFICATION EVIDENCE invariant, not a Runtime Gate. L5 owns
certification evidence; Runtime Gates (00C) and Exit (05) own live
ALLOW/DENY. A cross-child digest mismatch produces sealed L5_NOT_CERTIFIED
evidence; the consequent live disposition is owned by 00C/05 reading that
evidence. This file SHALL NOT define a runtime disposition.

PHASE 1 DATA CONTRACT — L5GovernanceContext
------------------------------------------------------------------------------------------------------------------------
The L5GovernanceContext is a frozen dataclass. Every required field below
the line is mandatory; optional fields are explicitly marked. The
canonical-JSON serialization sorts keys deterministically and is hashed
with SHA-256 to produce the l5_context_digest.

Identity fields (request- and tenant-scoped):
- request_id                       # opaque request id (frozen at intake)
- run_id                           # current-run id
- trace_id                         # OTEL trace id (root)
- tenant_id                        # tenant scope
- principal_id                     # resolved principal identity
- session_id                       # session id (or null when anonymous)

Routing / execution scope fields:
- route_id                         # L0-resolved route id
- step_id                          # nullable; L3 step id when L3-managed
- execution_form                   # one of L2_BOUNDED|L3_WORKFLOW|L1_ADVISORY|HITL_ONLY
- risk_tier                        # frozen risk tier band (from risk_tier_bands.md)
- side_effect_class                # READ_ONLY|TRANSIENT|DURABLE|EXTERNAL_EGRESS

Authority / policy / registry surface (the binding):
- policy_hash                      # SHA-256 of resolved policy snapshot
- blueprint_hash                   # SHA-256 of resolved blueprint snapshot
- registry_snapshot_hash           # SHA-256 of tool/model/agent registry view
- agent_profile_hash               # SHA-256 of resolved agent profile
- capability_scope_hash            # SHA-256 of resolved capability/permissions snapshot
- sandbox_envelope_hash            # SHA-256 of resolved sandbox envelope

Trust / egress / human-input surface:
- origin_trust_manifest_hash       # SHA-256 of origin-trust manifest in scope
- egress_profile_hash              # SHA-256 of egress profile in scope
- hitl_packet_hash                 # SHA-256 of HITL packet (null if HITL not applicable)
- reclearance_hash                 # SHA-256 of HITL re-clearance receipt (null if not applicable)

Certification evidence surface:
- replay_envelope_hash             # SHA-256 of replay envelope being certified
- audit_manifest_hash              # SHA-256 of audit manifest reference
- static_governance_snapshot_hash  # SHA-256 of static-governance / structure-drift snapshot

Certifier identity fields:
- certifier_id                     # opaque id of the L5 certifier emitting this digest
- certifier_version                # certifier version string
- certification_scope              # one of SAFETY|AUTHORITY|ORIGIN|HITL|EGRESS|REPLAY_AUDIT|STATIC_GOV|AGGREGATE

Frozen-context surface:
- frozen_governance_context_hash   # SHA-256 of the frozen 00A governance context
- l5_resolver_digest               # digest of the L5 resolver implementation

PHASE 2 DIGEST RULE
------------------------------------------------------------------------------------------------------------------------
- Serialize the L5GovernanceContext as canonical JSON (RFC 8785 / sort_keys=True,
  ensure_ascii=False, separators=(",", ":")).
- Compute SHA-256 over the UTF-8 byte representation.
- The hex digest is the l5_context_digest.
- Per-child digests inherit named aliases:
    safety_enforcement_digest          (emitted by 00A.1)
    authority_binding_digest           (emitted by 00A.2)
    origin_trust_digest                (emitted by 00A.3)
    hitl_reclearance_digest            (emitted by 00A.4 when HITL applies)
    egress_certification_digest        (emitted by 00A.5 when egress applies)
    replay_audit_digest                (emitted by 00A.6)
    static_governance_digest           (emitted by 00A.7)
    aggregate_governance_digest        (emitted by 00A.8 after equality check)
- Bit-for-bit equality is the only acceptable comparison. Substring,
  prefix, and field-subset comparisons are FORBIDDEN.
- The "when applicable" qualifier for HITL and Egress is determined by the
  packet's frozen execution_form and side_effect_class — never by certifier
  choice at run time.

PHASE 3 EQUALITY MATRIX
------------------------------------------------------------------------------------------------------------------------
For any packet certified by L5, the following MUST hold:

  REQUIRED (always):
    safety_enforcement_digest
    == authority_binding_digest
    == origin_trust_digest
    == replay_audit_digest
    == static_governance_digest

  CONDITIONALLY REQUIRED:
    hitl_reclearance_digest          MUST be present and equal whenever
                                     execution_form ∈ {HITL_ONLY} or the
                                     packet was escalated under 00A.4.
    egress_certification_digest      MUST be present and equal whenever
                                     side_effect_class ∈ {EXTERNAL_EGRESS}
                                     or the packet emits provider traffic
                                     classified by 00A.5.

  AGGREGATE:
    aggregate_governance_digest      MUST equal each required digest above.

If a conditionally required digest is absent when its trigger condition is
true, that absence is itself a mismatch (treated as L5_GOVERNANCE_CONTEXT_MISMATCH
with first_mismatched_field = "<conditional>_digest").

PHASE 4 INVARIANTS
------------------------------------------------------------------------------------------------------------------------
INV-L5C-1   For any packet that L5 certifies, all required and applicable
            conditionally-required per-child digests MUST be identical.
INV-L5C-2   The L5GovernanceContext is frozen at the moment the first
            L5 certifier emits its digest and SHALL NOT be mutated
            thereafter.
INV-L5C-3   No L5 child SHALL re-resolve any binding field independently —
            each child MUST consume the same L5GovernanceContext that
            produced the canonical l5_context_digest, OR produce a fresh
            context that hashes identically.
INV-L5C-4   Mismatch SHALL produce a sealed L5_NOT_CERTIFIED certification
            evidence record with terminal_class = L5_GOVERNANCE_CONTEXT_MISMATCH
            and decisive_rule_id = L5_GOVERNANCE_CONTEXT_MISMATCH.
INV-L5C-5   On mismatch the L5 plane SHALL NOT emit any per-child
            certification confirmation, SHALL NOT advance the packet to
            00A.8 aggregation, and SHALL NOT inhibit downstream Runtime
            Gate emission of an L5_BLOCKED verdict.
INV-L5C-6   The sealed L5_NOT_CERTIFIED record SHALL include every
            participating per-child digest, the first mismatched field
            name, the trace_id, and the replay refs sufficient for Exit
            Eval and L6 RCA to reproduce the rejection.
INV-L5C-7   Conditionally required digests (HITL, Egress) SHALL NOT be
            silently skipped. Their applicability is determined solely by
            execution_form and side_effect_class as frozen at intake.
INV-L5C-8   No L5 child may widen capability_scope_hash, sandbox_envelope_hash,
            policy_hash, blueprint_hash, or egress_profile_hash relative to
            the frozen context. Widening is itself a mismatch.
INV-L5C-9   This invariant SHALL NOT be substituted for a Runtime Gate.
            L5_NOT_CERTIFIED is certification evidence; live ALLOW/DENY
            is owned by 00C / 05.

------------------------------------------------------------------------------------------------------------------------

         step_id, execution_form, risk_tier, side_effect_class,
         policy_hash, blueprint_hash, registry_snapshot_hash,

         origin_trust_manifest_hash, egress_profile_hash, hitl_packet_hash,
         reclearance_hash, replay_envelope_hash, audit_manifest_hash,
         static_governance_snapshot_hash, l5_context_digest

l5.governance.child.emit
  attrs: certifier_id, certifier_version, certification_scope,
         l5_context_digest, child_digest_alias, trace_id

l5.governance.compare
  attrs: required_digests_seen, conditional_digests_seen,
         all_required_match (bool), conditional_match (bool),
         first_mismatched_field (empty when match), trace_id, decision_id

l5.governance.aggregate
  attrs: aggregate_governance_digest, all_match (bool), trace_id,
         certified (bool), terminal_class

l5.governance.blocked
  attrs: decisive_rule_id (= L5_GOVERNANCE_CONTEXT_MISMATCH),
         first_mismatched_field, trace_id, sealed_evidence_id, terminal_class

PHASE 6 SEALED L5_NOT_CERTIFIED EVIDENCE
------------------------------------------------------------------------------------------------------------------------
On INV-L5C-1 violation, L5 emits a CertificationEvidence record carrying:
  - terminal_stamp = L5_GOVERNANCE_CONTEXT_MISMATCH
  - decisive_reason = "<child>_digest != <child>_digest" (first mismatch)
  - certified = false
  - certification_scope = AGGREGATE
  - downstream_recommendation = "deny"
  - dispatch_target = EXIT_CONTROL
  - participating_digests = { safety_enforcement_digest, authority_binding_digest,
        origin_trust_digest, hitl_reclearance_digest, egress_certification_digest,
        replay_audit_digest, static_governance_digest, aggregate_governance_digest }
  - first_mismatched_field, trace_id, sealed_evidence_id all sealed into the
    record body.

PHASE 7 TEST CONTRACT (mandatory)
------------------------------------------------------------------------------------------------------------------------
Every L5-active route SHALL be exercised by a matrix test that asserts the
following columns for each certified packet:

  request_id, run_id, route_id, execution_form, risk_tier,
  side_effect_class, safety_enforcement_digest, authority_binding_digest,
  origin_trust_digest, hitl_reclearance_digest, egress_certification_digest,
  replay_audit_digest, static_governance_digest, aggregate_governance_digest,
  certified, expected_terminal_class, trace_id, sealed_evidence_id

Negative scenarios required (cross-reference 00A.8a expanded test list):
  A  policy_hash_mismatch                  policy_hash differs across children
  B  blueprint_hash_mismatch                blueprint_hash differs across children
  C  registry_snapshot_mismatch             registry_snapshot_hash differs
  D  capability_widening                    capability_scope_hash widened by one child
  E  sandbox_widening                       sandbox_envelope_hash widened by one child
  F  origin_trust_drift                     origin_trust_manifest_hash differs
  G  egress_profile_drift                   egress_profile_hash differs (when applicable)
  H  hitl_packet_swap                       hitl_packet_hash differs (when applicable)
  I  reclearance_missing                    reclearance_hash absent when HITL applies
  J  replay_envelope_drift                  replay_envelope_hash differs
  K  audit_manifest_drift                   audit_manifest_hash differs
  L  static_governance_drift                static_governance_snapshot_hash differs
  M  conditional_digest_skipped             egress_certification_digest absent when EXTERNAL_EGRESS
  N  certifier_self_widening                child re-resolved a binding field
  O  aggregate_without_all_required         aggregate emitted while required child missing

Each negative scenario MUST assert: certified=false, no aggregate_governance_digest
emission, sealed evidence carries L5_GOVERNANCE_CONTEXT_MISMATCH (or scenario-
specific terminal class), trace_id present, and no downstream child of 00A
proceeds.
