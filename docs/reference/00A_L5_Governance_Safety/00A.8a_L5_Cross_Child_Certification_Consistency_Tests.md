PHASE 1 FIXTURE CONTRACT
------------------------------------------------------------------------------------------------------------------------
Every test MUST consume a synthesized L5GovernanceContext with all
required and conditionally-required fields populated by deterministic
seeds. The fixture API:

  build_l5_context(
      seed: str,
      execution_form: ExecutionForm,
      side_effect_class: SideEffectClass,
      hitl_required: bool = False,
      egress_required: bool = False,
  ) -> L5GovernanceContext

  emit_child_digest(
      ctx: L5GovernanceContext,
      certifier_scope: CertificationScope,
      mutate_field: str | None = None,
      mutate_value: Any | None = None,
  ) -> str  # returns the per-child hex digest

The mutate_field parameter is the anti-cheat lever. When None, the child
emits a digest of the unmodified ctx (positive case). When set, the child
mutates exactly one field before serialization, producing a deterministic
mismatch.

PHASE 2 POSITIVE COVERAGE
------------------------------------------------------------------------------------------------------------------------
P-1   All required children emit equal digests; aggregate emits an
      identical aggregate_governance_digest. certified=true.

P-2   All required children plus HITL conditional digest emit equal
      digests when execution_form ∈ {HITL_ONLY}. certified=true.

P-3   All required children plus Egress conditional digest emit equal
      digests when side_effect_class ∈ {EXTERNAL_EGRESS}. certified=true.

P-4   All required + both conditional digests equal when both triggers
      fire. certified=true.

For each P-row:
  - Assert l5.governance.context.frozen span carries every required field.
  - Assert l5.governance.child.emit span fires once per certifier with
    matching l5_context_digest.
  - Assert l5.governance.compare span carries all_required_match=true and
    conditional_match=true (or N/A when no conditional applies).
  - Assert l5.governance.aggregate span carries certified=true and
    aggregate_governance_digest equal to every child digest.

PHASE 3 NEGATIVE / ANTI-CHEAT COVERAGE
------------------------------------------------------------------------------------------------------------------------
Each row mutates exactly one field at one child, with all other children
honest. The aggregate MUST refuse to emit and L5 MUST seal an
L5_NOT_CERTIFIED record.

  Row  Scenario                                Mutated field at one child
  N-A  policy_hash_mismatch                    policy_hash
  N-B  blueprint_hash_mismatch                  blueprint_hash
  N-C  registry_snapshot_mismatch               registry_snapshot_hash
  N-D  agent_profile_drift                      agent_profile_hash
  N-E  capability_widening                      capability_scope_hash
  N-F  sandbox_widening                         sandbox_envelope_hash
  N-G  origin_trust_drift                       origin_trust_manifest_hash
  N-H  egress_profile_drift                     egress_profile_hash
  N-I  hitl_packet_swap                         hitl_packet_hash
  N-J  reclearance_drift                        reclearance_hash
  N-K  replay_envelope_drift                    replay_envelope_hash
  N-L  audit_manifest_drift                     audit_manifest_hash
  N-M  static_governance_drift                  static_governance_snapshot_hash
  N-N  resolver_drift                           l5_resolver_digest
  N-O  frozen_context_drift                     frozen_governance_context_hash

For each N-row, assert:
  - l5.governance.compare span carries all_required_match=false and
    first_mismatched_field equal to the mutated field name.
  - l5.governance.aggregate span MUST NOT emit aggregate_governance_digest.
  - l5.governance.blocked span fires with
    decisive_rule_id=L5_GOVERNANCE_CONTEXT_MISMATCH.
  - Sealed CertificationEvidence record exists with certified=false,
    terminal_stamp=L5_GOVERNANCE_CONTEXT_MISMATCH, and every participating
    digest sealed in the record body.
  - No downstream 00A child certification confirmation is emitted.

PHASE 4 APPLICABILITY COVERAGE
------------------------------------------------------------------------------------------------------------------------
A-1   hitl_skipped_when_required:
      execution_form=HITL_ONLY but hitl_reclearance_digest absent →
      first_mismatched_field="hitl_reclearance_digest", certified=false.

A-2   egress_skipped_when_required:
      side_effect_class=EXTERNAL_EGRESS but egress_certification_digest
      absent → first_mismatched_field="egress_certification_digest",
      certified=false.

A-3   hitl_emitted_when_not_required:
      execution_form ∉ {HITL_ONLY} and packet not escalated under 00A.4
      but hitl_reclearance_digest present → MUST be sealed as
      conditional_digest_unexpected (treated as mismatch).

A-4   egress_emitted_when_not_required:
      side_effect_class ∉ {EXTERNAL_EGRESS} but egress_certification_digest
      present → MUST be sealed as conditional_digest_unexpected.

PHASE 5 ANTI-BYPASS COVERAGE
------------------------------------------------------------------------------------------------------------------------
B-1   self_widening_attempt:
      A child certifier resolves capability_scope_hash internally rather
      than consuming the frozen context. Test asserts the consistency
      gate detects the rederived value differs and seals
      L5_GOVERNANCE_CONTEXT_MISMATCH.

B-2   aggregate_without_all_required:
      00A.8 attempts to emit aggregate_governance_digest while one
      required child digest is absent. Test asserts the aggregator
      refuses (no aggregate emitted) and seals
      L5_GOVERNANCE_CONTEXT_MISMATCH with first_mismatched_field naming
      the absent child digest alias.

B-3   substring_or_prefix_compare:
      A test wraps the compare function to use prefix comparison; the
      consistency gate MUST fail this test (i.e., the production code
      MUST refuse non-bit-equal comparison).

B-4   post_freeze_mutation:
      A child mutates the L5GovernanceContext after the frozen span
      fires. Test asserts the mutation is rejected by the immutability
      guard with a sealed L5_GOVERNANCE_CONTEXT_MISMATCH carrying
      first_mismatched_field=frozen_governance_context_hash.

PHASE 6 OTEL ASSERTION SHAPE
------------------------------------------------------------------------------------------------------------------------
For every test row, the OTEL exporter under test MUST surface:
  - exactly one l5.governance.context.frozen span per packet
  - one l5.governance.child.emit span per participating child
  - exactly one l5.governance.compare span per packet
  - at most one l5.governance.aggregate span per packet (zero on mismatch)
  - exactly one l5.governance.blocked span on mismatch (zero on match)

Tests MUST verify span attributes, not just span names. Missing
attributes are treated as test failures.

PHASE 7 COVERAGE MATRIX ROW SCHEMA
------------------------------------------------------------------------------------------------------------------------
Tests register coverage rows against v5_coverage_matrix.md (or the
00A-equivalent matrix file) using the schema:

  Requirement -> owner_file -> emitting_child -> enforcing_child ->
  digest_field -> test_id -> otel_span -> sealed_evidence_id

For 00A.7a / 00A.8a, the requirement column is one of the INV-L5C-* rows
in 00A.7a Phase 4. Every invariant SHALL have at least one positive and
