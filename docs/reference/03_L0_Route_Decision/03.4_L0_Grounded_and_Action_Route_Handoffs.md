OBJECTIVE
------------------------------------------------------------------------------------------------------------------------
Implement the route handoff packets for simple grounded read and bounded single action.

L0.4 answers one question only:
"What bounded downstream handoff is required for this selected single-step route?"

R3 SIMPLE GROUNDED READ
------------------------------------------------------------------------------------------------------------------------
Path:
L0 -> C0 -> Prompt Assembly -> L2 -> Exit

Use when:
- factual/source/policy/code/document/user-file/currentness support is required.
- the task can be satisfied by one C0 evidence contract and one L2 synthesis step.
- no dependency-changing workflow is required.

Route obligations:
- grounding_required = true
- support_target required
- citation_mode bound
- freshness_class bound
- C0 max_k/max_hops/max_refine_attempts bound
- Prompt Assembly required
- L2 receives one bounded prompt/model packet
- L3 bypassed

R4 SINGLE ACTION
------------------------------------------------------------------------------------------------------------------------
Path:
L0 -> L2 -> Exit

Use when:
- one reversible or low-risk action is requested.
- args are complete and unambiguous.
- capability_token and sandbox_envelope can be bound downstream.
- no staged evidence or step dependency is required.

Route obligations:
- grounding_required usually false
- action_spec required
- capability_class required
- sandbox_class required
- side_effect_class bound
- write_authority = NONE_UNTIL_UWG
- L2 executes one bounded packet
- Exit reviews sealed result
- L3 bypassed

R3 + R4 ACTION ARGUMENT GROUNDING
------------------------------------------------------------------------------------------------------------------------
Path:
L0 -> C0 -> Prompt Assembly or argument packet -> L2 -> Exit

Use when:
- one action is still single-step but needs grounded argument lookup.
- example: "Draft a reply using the latest email in this thread."
- example: "Create an event using the date from this document."

Route obligations:
- C0 grounds action arguments only.
- C0 does not authorize the action.
- Prompt Assembly or structured argument packet packages verified argument context.
- L2 executes the action packet inside capability/sandbox.
- Exit reviews result before any egress/commit.

PTC-CAPABLE SINGLE STEP
------------------------------------------------------------------------------------------------------------------------
A route handoff may set:
- ptc_candidate = true
- ptc_batch_reason = tool_call_batching | context_isolation | cost_reduction | raw_output_containment
- ptc_requires_l2_sandbox = true
- ptc_requires_l5_egress_certification = true
- ptc_raw_tool_results_must_not_enter_l1_or_l3_context = true
- ptc_stdout_summary_only_to_model_context = true

This is only a downstream execution permission. It is not execution.

- PTC flags must not skip Exit.
