OBJECTIVE
------------------------------------------------------------------------------------------------------------------------
Implement L0.1 as the preflight desk that confirms the L1 plan is routeable and extracts the discriminators L0 needs.

L0.1 answers one question only:
"Do we have a valid, policy-bound, route-ready input frame for deterministic route selection?"

L0.1 does not choose the final route. It prepares the route candidate frame for L0.2.

HARD FAIL CONDITIONS
------------------------------------------------------------------------------------------------------------------------
- missing request_id / trace_root / replay_key
- missing policy_hash / blueprint_hash
- L1 claims final route authority
- L1 already retrieved final evidence
- L1 already executed a tool/model/script
- L1 already wrote durable state
- tenant or ACL boundary cannot be established
- action target is ambiguous and irreversible
- source expectation is critical but no source handle exists

ACCEPTANCE TESTS
------------------------------------------------------------------------------------------------------------------------
- malformed L1 plan fails closed.
- L1 route hint is treated as advisory only.
- source-grounded task marks C0 likely required.
- one reversible action marks single-step likely.
- multi-hop dependency task marks L3 likely.
- PTC-capable request is marked as downstream L2-capable, not executed.
- no durable write path exists from L0.1.
