OBJECTIVE
------------------------------------------------------------------------------------------------------------------------
Implement the L3 completion and control plane.

L3.8 answers one question only:
"Has the managed workflow completed safely enough to seal a workflow package for Exit, or should it continue through a
bounded ready-node/fallback/partial path?"

PHASE 2 CONCURRENCY GOVERNOR
------------------------------------------------------------------------------------------------------------------------

govern_concurrency(ledger, workflow_blueprint) -> ConcurrencyPlan

Checks:
- independence of shards
- policy/HITL dependencies
- shared resource risk
- race risk
- deterministic join order
- resource ceilings
- per-branch budget

PHASE 3 QUALITY LOOP GOVERNOR
------------------------------------------------------------------------------------------------------------------------

govern_quality_loop(ledger, quality_loop_plan) -> NodeReadinessDecision | StopLoopReceipt

Stop conditions:
- quality threshold achieved
- max iterations reached
- budget exhausted
- SLO exhausted
- oscillation detected
- no material improvement
- safety/policy blocker
- best partial should be sealed

PHASE 4 FALLBACK / CASCADE CONTROL
------------------------------------------------------------------------------------------------------------------------

apply_fallback_control(step_result, fallback_state) -> FallbackCascadeState

Rules:
- ordered fallback only
- reason_code required
- no silent fallback
- provider/tool alternatives must remain inside registry/capability/sandbox bounds
- tier escalation requires executor uncertainty, not desired-answer shopping
- failed fallback emits safe partial or Exit-facing failure when chain exhausted

PHASE 5 COMPLETION / EXIT PACKAGE
------------------------------------------------------------------------------------------------------------------------

run_completion_test(ledger, context_bus, workflow_blueprint) -> WorkflowCompletionTest

If COMPLETE or COMPLETE_DEGRADED or SAFE_PARTIAL_READY:
- emit SealedWorkflowPackage to Exit.

If NEEDS_NEXT_NODE:
- return to L3.7 ready-node selection.

If NEEDS_HITL_PAUSE:
- emit bounded pause packet for L5/HITL re-clearance path.

If FAILED_TERMINAL or ABSTAIN_RECOMMENDED:
- seal best partial and reason codes for Exit.

HARD LAWS
------------------------------------------------------------------------------------------------------------------------
- L3 does not decide ALLOW_FINISH.
- L3 does not make final denial.
- L3 does not commit.
- L3 does not let L6 learning modify current run.
- L3 carries proposed mutations only as proposed_state_diff_refs.
- Exit receives the package and decides current-run disposition.

ACCEPTANCE TESTS
------------------------------------------------------------------------------------------------------------------------
- Independent shards fan out with deterministic join.
- Dependent nodes do not fan out.
- Quality loop stops at max_iterations.
- Fallback chain is ordered and reason-coded.
- Route identity uncertainty does not trigger confidence cascade.
- Completion package includes all sealed L2 artifacts.
- Mutations remain proposal-only.
- SealedWorkflowPackage goes to Exit, not L4.
- L6 receives exhaust only after current run is over.
