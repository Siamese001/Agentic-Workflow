OBJECTIVE
------------------------------------------------------------------------------------------------------------------------
Implement terminal route decisions as deterministic, reviewable route packets.

L0.3 answers one question only:
"Can this run safely short-circuit before C0/Prompt Assembly/L2, or does it require a human-gated posture?"

TERMINAL ROUTE FAMILY
------------------------------------------------------------------------------------------------------------------------

R1A_EXACT_CACHE:
- Perfect keyed reuse.
- Zero inference.
- No C0.
- No Prompt Assembly.
- No L3.
- No L2.
- Returns [RET] packet to Exit.

R1B_SEMANTIC_CACHE:
- Bounded reuse for stable, reuse-safe tasks.
- Uses calibrated similarity and task compatibility.
- No C0.
- No Prompt Assembly.
- No L3.
- No L2.
- Returns [RET] packet to Exit.

R5_FALLBACK:
- Safe clarify, abstain, refuse, safe partial, or unsupported-source response packet.
- No C0 when the issue is scope/safety/source absence.
- No L3.
- No L2 unless downstream policy explicitly wraps a fallback response for generation, which must be routed separately.
- Returns [RET] packet to Exit.

HITL_POSTURE:
- Not sovereign authority.
- Not direct approval.
- A route annotation requiring bounded human review downstream.
- Human review output is data and must be re-cleared through L5/Exit.
- Durable writes still require UWG.

RULES
------------------------------------------------------------------------------------------------------------------------

R1A hard no:
- expired freshness
- policy drift
- tenant mismatch
- schema mismatch
- prior weak/conflicted support
- changed source snapshot for source-grounded answer
- high-stakes current claim without explicit policy permission

R1B hard no:
- latest/current/recent request
- attached-file Q&A
- legal/medical/financial/regulatory claim unless approved
- user-specific private source obligation
- action/mutation intent
- low similarity
- task class mismatch
- policy drift

R5 hard no:
- no vague success. Fallback must state why and what safe bounded outcome is possible.
- no hidden tool call.
- no fabricated evidence.
- no direct write.
- no ambiguous recipient/action expansion.

HITL hard no:
- human approval cannot bypass L5.
- human modification cannot bypass Exit.
- human acceptance cannot commit to L4.
- human notes cannot become system authority.
