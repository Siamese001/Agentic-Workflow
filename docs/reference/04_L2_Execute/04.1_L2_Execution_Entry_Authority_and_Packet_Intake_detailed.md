PHASE 2 ENTRY PIPELINE
------------------------------------------------------------------------------------------------------------------------
1. Receive packet from governed channel only.
2. Normalize source shape without flattening lineage.
3. Bind L0/L3 authority references.
4. Check required shared metadata.
5. Attach L2 boundary assertions.
6. Emit L2ExecutionRequest for E1.

PHASE 3 FAILURE MODES
------------------------------------------------------------------------------------------------------------------------
Fail closed if:
- packet has no route_contract_ref
- packet issuer is not L0 or L3
- packet is unsigned
- packet route_digest does not match source route
- packet tries to grant durable write authority
- packet contains user or human text in an authority field
- packet asks L2 to retrieve, route, plan, expand workflow, or approve output
- PTC packet lacks script digest or sandbox profile

PHASE 4 ACCEPTANCE TESTS
------------------------------------------------------------------------------------------------------------------------
- unsigned packet rejected before E1
- L3 step without parent route rejected
- PTC marker does not execute during entry
- direct write authority flag rejected
- route change request rejected
- human review text cannot become authority
- entry receipt preserves route, plan, prompt, evidence, and step refs
