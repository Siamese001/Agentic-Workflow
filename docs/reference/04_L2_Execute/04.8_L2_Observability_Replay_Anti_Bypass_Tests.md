PHASE 3 ANTI-BYPASS TESTS
------------------------------------------------------------------------------------------------------------------------
Tests must fail if:
- L2 writes directly to L4.
- L2 calls UWG directly without Exit cleared packet.
- L2 emits ALLOW_FINISH or final Exit disposition.
- L2 changes route_id or route_digest.
- L2 expands workflow nodes.
- L2 performs C0 retrieval without explicit bounded read/tool action.
- L2 builds PromptEnvelope itself.
- L2 asks human directly.
- L2 treats human input as authority.
- L2 silently switches provider/model/tool/credential/sandbox.
- L2 runs without capability_token.
- L2 runs without sandbox_envelope.
- L2 repairs under changed policy_hash or blueprint_hash.
- L2 fails to seal rejection/failure.
- PTC leaks raw tool results into model context.
- PTC performs untranscripted IO.
