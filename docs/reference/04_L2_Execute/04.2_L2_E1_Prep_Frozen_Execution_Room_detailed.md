PHASE 2 WORKSTEPS
------------------------------------------------------------------------------------------------------------------------
E1.1 Packet receive
- Accept exactly the signed L0 packet or L3 step passed by entry.
- Refuse partial, unsigned, stale, mutated, or metadata-incomplete packets.
- Preserve original task payload separately from normalized execution fields.

E1.2 Authority bind
- Bind route_id, step_id, capability_token, compliance_hash, sandbox_envelope, issuer identity.
- Reject authority inferred from user wording, tool name, human note, retrieved text, or model output.

E1.3 Environment freeze
- Lock registry versions, model/provider lane, filesystem view, network rules, secrets scope, locale, budgets.
- Freeze relevant environment variables and prohibit late discovery.

E1.4 Determinism bind
- Bind blueprint_hash, policy_hash, prompt_hash, input_hash, replay_key, attempt_seed, snapshot_manifest.
- Convert wall-clock needs to run-clock offsets when replay is required.

E1.5 Idempotency guard
- Derive stable run_id and idempotency_key.
- Detect duplicate packet family, duplicate tool call, duplicate model request, and replay resume collision.
- If duplicate is already sealed, return prior sealed receipt instead of rerunning.

E1.6 Lineage root
- Attach ancestry chain across L1, L0, C0, PA, L3 where present.
- Create L2 lineage root for attempts, repairs, errors, and artifacts.

E1.7 Write lock
- Verify no direct L4/UWG commit path.
- Disable direct persistence, live memory update, cache promotion, unapproved credential write, external irreversible side effect.

E1.8 Start receipt
- Emit prep_receipt with frozen inputs, caps, budgets, lineage, hashes, environment digest, replay metadata.

- policy_hash mismatch
- stale blueprint_hash
- duplicate in-flight idempotency key
- no replay snapshot for replay-required route
