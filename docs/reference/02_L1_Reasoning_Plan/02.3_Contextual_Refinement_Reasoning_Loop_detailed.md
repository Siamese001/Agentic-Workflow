PHASE 2 PIPELINE
------------------------------------------------------------------------------------------------------------------------
Required public entrypoint:

run_l1_reasoning_loop(input: PlanningReasoningInput) -> PlanningReasoningPacket

Required stages:
1. Create initial InternalPlanState from IntentFrame and PlanBundle.
2. Run bounded refinement pass focused on constraints and deliverable.
3. Run bounded refinement pass focused on support/action/risk markers.
4. Run simplification pass to remove unnecessary workflow/tool complexity.
5. Stop when stable, max passes reached, clarify recommended, abstain recommended, or policy review marker appears.
6. Emit PlanningReasoningTraceSummary without chain-of-thought.
