PHASE 3 ROUTE HINT CONSISTENCY RULES
------------------------------------------------------------------------------------------------------------------------
- R1A exact cache hint requires exact normalized_request_hash reuse potential, compatible policy, stable freshness, and no
  source-specific/current/action/write need.
- R1B semantic cache hint requires reuse-safe task class, high similarity expectation, compatible schema, stable task, and no
  file/current/high-stakes obligation.
- R3 grounded read hint requires factual, file, code, policy, source, current, verification, or citation support need.
- R4 single action hint requires one bounded reversible/low-risk action and no workflow state.
- R3R4 managed workflow hint requires dependencies, branching, joins, staged evidence, retries, parallel shards, or resumable state.
- R5 fallback hint requires unsafe, unsupported, insufficient, invalid, or clarification/abstain posture.
