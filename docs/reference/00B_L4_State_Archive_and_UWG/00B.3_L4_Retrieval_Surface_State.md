PHASE 2 READ-ONLY C0 ACCESS REQUIREMENTS
------------------------------------------------------------------------------------------------------------------------
L4 must expose read-only handles to C0:
- open_retrieval_surface(snapshot_id, tenant_scope, policy_hash) -> RetrievalSurfaceManifest
- resolve_source_chunk(source_id, source_version, chunk_id, tenant_scope) -> SourceChunkManifest
- resolve_citation_anchor(anchor_id, tenant_scope, snapshot_id) -> CitationAnchorRecord
- get_vector_index(index_id, tenant_scope, snapshot_id) -> VectorIndexManifest
- get_sparse_index(index_id, tenant_scope, snapshot_id) -> SparseIndexManifest
- get_metadata_index(index_id, tenant_scope, snapshot_id) -> MetadataIndexManifest
- get_graph_projection(graph_projection_id, tenant_scope, snapshot_id) -> GraphProjectionManifest

Rules:
- C0 may read surfaces but cannot mutate them.
- Reads must enforce ACL and tenant scope before returning handles.
- Retrieval surfaces must expose version/snapshot/freshness metadata.
- Missing citation anchor must be visible as citation risk, not hidden.
- Graph projection reads must preserve relation/source lineage and projection_version.

PHASE 3 INDEX AND PROJECTION MANIFEST RULES
------------------------------------------------------------------------------------------------------------------------
Every index/projection must record:
- source snapshot refs
- build receipt ref
- index/projection hash
- embedding/tokenizer/schema version where applicable
- ACL filter profile
- freshness timestamp
- tenant scope
- audit refs

Forbidden:
- vector index without source snapshot ref
- sparse index without tokenizer/version ref
- metadata index without field manifest
- graph projection without projection_version
- graph projection refresh without source snapshot ref
- citation anchor without source version
- read surface refresh without commit receipt

PHASE 4 FAILURE MODES
------------------------------------------------------------------------------------------------------------------------
Fail closed or mark unavailable when:
- source snapshot stale
- index manifest missing
- index hash mismatch
- vector dimension mismatch
- BM25/sparse manifest missing tokenizer/version
- metadata index lacks required tenant/ACL filters
- graph projection stale
- citation anchor missing for exact quote support target
- source manifest points outside tenant scope
- runtime graph snapshot lacks trace lineage
- ADG snapshot lacks snapshot_id

PHASE 6 TEST REQUIREMENTS
------------------------------------------------------------------------------------------------------------------------
Tests must fail if:
- C0 mutates retrieval surface
- L4 read returns source outside tenant/ACL scope
- vector index lacks source snapshot ref
- sparse index lacks tokenizer/version manifest
- graph projection lacks projection_version
- graph projection refresh lacks source snapshot ref
- citation anchor resolves against wrong source_version
- stale source appears as fresh
- grounded cache entry points to missing evidence contract or missing source lineage
- replay reconstruction cannot resolve retrieval surface snapshot

ACCEPTANCE CRITERIA
------------------------------------------------------------------------------------------------------------------------
- Retrieval surfaces are versioned, ACL-scoped, freshness-aware, and read-only to C0.
- Index/projection manifests preserve source snapshot lineage.
- Citation anchors are stable and auditable.
- Retrieval reads emit OTEL and preserve replay identifiers.
