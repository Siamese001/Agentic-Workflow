PHASE 2 REFRESH TYPES
------------------------------------------------------------------------------------------------------------------------
Supported refresh targets:
- policy alias
- registry alias
- cache invalidation
- vector index rebuild
- sparse/BM25 index rebuild
- graph projection rebuild
- metadata index refresh
- memory projection refresh
- prompt BOM cache refresh
- route baseline refresh
- schema registry projection refresh
- grader roster projection refresh

Refresh rules:
- Refresh only after UWGCommitReceipt.
- Refresh must declare before_snapshot and after_snapshot or stale warning.
- Failed refresh cannot be hidden.
- Stale projection warning must be visible to readers and Exit/L6 audit paths.
- Cache invalidation must happen before readers can use stale cache after source/policy/registry change.
- Alias refresh must be atomic where readers require consistency.
- Index rebuild receipts must point to source snapshot refs.

PHASE 3 REFRESH ORDERING
------------------------------------------------------------------------------------------------------------------------
Default ordering:
1. policy/schema/registry alias changes
2. cache invalidation
3. source/chunk manifest projection
4. metadata index refresh
5. sparse index rebuild
6. vector index rebuild
7. graph projection rebuild
8. memory projection refresh
9. prompt BOM cache refresh
10. route baseline refresh
11. publish L4SnapshotManifest after required refreshes complete or stale warnings are recorded

Rules:
- Do not publish a clean after_snapshot if required refresh failed.
- Do not allow cache lookup to treat invalidated cache as compatible.
- Do not allow C0 read handles to hide stale vector/sparse/graph projection warnings.
- Do not rebuild graph projection without source snapshot ref.

PHASE 4 FAILURE MODES
------------------------------------------------------------------------------------------------------------------------
Fail closed or emit stale warning when:
- source commit receipt missing
- before_snapshot missing
- after_snapshot cannot be produced
- required refresh fails
- index rebuild fails
- graph projection refresh lacks source snapshot ref
- cache invalidation fails after source/policy change
- alias refresh points to unknown immutable record
- prompt BOM cache refresh fails after prompt slot registry change
- route baseline refresh fails after route registry change
- refresh receipt cannot append audit ledger
