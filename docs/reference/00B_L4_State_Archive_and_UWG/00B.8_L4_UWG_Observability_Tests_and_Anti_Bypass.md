PHASE 3 ANTI-BYPASS TEST MATRIX
------------------------------------------------------------------------------------------------------------------------
Required tests that must fail if:
- L2 writes directly to L4.
- L6 writes directly to L4.
- HITL writes directly to L4.
- Exit mutates L4 instead of emitting CommitRequest.
- L5 outputs runtime dispositions or commits state.
- C0 mutates retrieval surfaces.
- Prompt Assembly mutates prompt registry or memory directly.
- PTC sandbox writes directly to L4.
- Tools/models/connectors write durable state directly.
- Background evaluator writes durable state directly.
- Ad hoc script writes durable state without UWG transaction.
- Direct file/DB write path bypasses UWG.
- Policy update happens without versioning.
- Registry update happens without registry_digest.
- Cache entry lacks policy_hash compatibility.
- Grounded cache entry lacks evidence contract ref.
- Memory promotion accepts raw telemetry.
- Read projection refresh happens without commit receipt.
- Rollback lacks before_snapshot.
- L4 read returns data outside tenant/ACL scope.
- Replay snapshot cannot reconstruct committed state.
