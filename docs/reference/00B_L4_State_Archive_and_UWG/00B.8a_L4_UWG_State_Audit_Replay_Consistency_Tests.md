PHASE 1 FIXTURE CONTRACT
------------------------------------------------------------------------------------------------------------------------
Every test MUST consume a synthesized DurableWriteContext with all
required fields populated by deterministic seeds. The fixture API:

  build_durable_write_context(
      seed: str,
      mutation_intent_class: MutationIntentClass,
      l5_certified: bool = True,
      idempotency_key: str | None = None,
  ) -> DurableWriteContext

  emit_stage_digest(
      ctx: DurableWriteContext,
      stage: WriteStage,                # one of EXIT_COMMIT_REQUEST, UWG_VALIDATION,
                                        # WRITE_LOCK, COMMIT_TXN, L4_STATE_RECEIPT,
                                        # AUDIT_LEDGER, REPLAY_SNAPSHOT,
                                        # RETRIEVAL_CACHE_INVALIDATION
      mutate_field: str | None = None,
      mutate_value: Any | None = None,
      delay_until_after: WriteStage | None = None,  # for ordering tests
  ) -> str  # returns the per-stage hex digest

When mutate_field is None, the stage emits a digest of the unmodified
ctx (positive case). When set, the stage mutates exactly one field
before serialization, producing a deterministic mismatch.
delay_until_after enables out-of-order tests.

PHASE 2 POSITIVE COVERAGE
------------------------------------------------------------------------------------------------------------------------
P-1   All 8 stages emit equal digests in canonical order; committed=true,
      l4_state_receipt observed, audit appended, replay snapshot indexed,
      retrieval and cache invalidations observed.

P-2   Idempotency replay: second admission with identical
      idempotency_key returns the original l4_state_receipt_digest;
      no second L4 write, no second audit append, no second snapshot;
      OTEL span carries idempotency_replay=true.

P-3   CREATE / UPDATE / DELETE / UPSERT / TOMBSTONE: one positive run
      per mutation_intent_class; all assert chain equality.

P-4   L5 certification present and equal: l5_certification_packet_hash
      equals aggregate_governance_digest from 00A.7a fixture; UWG admits.

For each P-row:
  - Assert uwg.write.context.frozen span carries every required field.
  - Assert uwg.write.stage.emit span fires once per stage in canonical order.
  - Assert uwg.write.compare span carries chain_complete=true and all_match=true.
  - Assert uwg.write.committed span carries every receipt digest.

PHASE 3 NEGATIVE / ANTI-CHEAT COVERAGE
------------------------------------------------------------------------------------------------------------------------
Each row mutates exactly one field at one stage, with all other stages
honest. The chain MUST refuse to advance and UWG MUST seal a
NO_DURABLE_MUTATION receipt.

  Row  Scenario                              Mutated field at one stage
  N-A  intent_class_drift                    mutation_intent_class
  N-B  schema_drift                          schema_hash
  N-C  state_diff_drift                      state_diff_candidate_hash
  N-D  before_snapshot_drift                 before_snapshot_hash
  N-E  after_candidate_drift                 after_candidate_hash
  N-F  policy_drift                          policy_hash
  N-G  blueprint_drift                        blueprint_hash
  N-H  capability_widening                    capability_scope_hash
  N-I  sandbox_widening                       sandbox_envelope_hash
  N-J  target_store_drift                     target_store_id
  N-K  target_object_drift                    target_object_ref
  N-L  replay_key_swap                        replay_key
  N-M  lock_id_swap                           write_lock_id
  N-N  txn_id_swap                            transaction_id
  N-O  audit_manifest_drift                   audit_manifest_hash
  N-P  rollback_plan_drift                    rollback_plan_hash
  N-Q  replay_snapshot_drift                  replay_snapshot_hash
  N-R  retrieval_invalidation_drift           retrieval_invalidation_plan_hash
  N-S  cache_invalidation_drift               cache_invalidation_plan_hash
  N-T  read_surface_refresh_drift             read_surface_refresh_plan_hash
  N-U  resolver_drift                         uwg_resolver_digest
  N-V  frozen_context_drift                   frozen_durable_write_context_hash

For each N-row, assert:
  - uwg.write.compare span carries chain_complete=false (or all_match=false)
    and first_mismatched_stage equal to the stage that observed the mutation.
  - uwg.write.committed span MUST NOT emit for any post-mismatch stage.
  - uwg.write.blocked span fires with decisive_rule_id=UWG_COMMIT_BLOCKED.
  - Sealed NoDurableMutationReceipt exists with committed=false,
    terminal_stamp=DURABLE_WRITE_CONTEXT_MISMATCH, and every emitted
    stage digest sealed in the receipt body.
  - L4 store reflects no mutation; audit ledger reflects no append for
    this attempt; replay snapshot index reflects no new entry.

PHASE 5 IDEMPOTENCY / REPLAY COVERAGE
------------------------------------------------------------------------------------------------------------------------
I-1   exact_replay_dedupe:
      Two admissions with identical idempotency_key, identical
      state_diff_candidate_hash → second is a deduplicated no-op
      returning the original l4_state_receipt_digest.

I-2   replay_with_changed_diff:
      Two admissions with identical idempotency_key but different

I-3   replay_key_reuse_across_request:
      Same replay_key used for two different request_ids → second is
      rejected with first_mismatched_field="replay_key".

PHASE 6 BYPASS-ATTEMPT COVERAGE
------------------------------------------------------------------------------------------------------------------------
B-1   direct_l4_without_uwg:
      Test stub attempts to call the L4 state store directly without an
      uwg_validation_digest. Test asserts the consistency gate detects
      the absence and seals NO_DURABLE_MUTATION; no L4 mutation
      observed.

B-2   uwg_without_exit_commit_request:
      UWG admission attempted without exit_commit_request_digest.
      Test asserts UWG refuses (no admission digest emitted) and seals
      DURABLE_WRITE_CONTEXT_MISMATCH with first_mismatched_stage=
      "exit_commit_request_digest".

B-3   l5_certification_missing:
      Admission attempted with l5_certification_packet_hash=null.
      Test asserts UWG refuses and seals UWG_COMMIT_BLOCKED with
      first_mismatched_field="l5_certification_packet_hash".

B-4   l5_certification_mismatch:
      Admission attempted with l5_certification_packet_hash !=
      aggregate_governance_digest from 00A.7a fixture. Test asserts
      UWG refuses and seals UWG_COMMIT_BLOCKED.

B-5   substring_or_prefix_compare:
      Test wraps compare with prefix comparison; production code MUST
      refuse non-bit-equal comparison.

B-6   post_freeze_mutation:
      A stage mutates the DurableWriteContext after the frozen span
      fires. Test asserts the mutation is rejected by the immutability
      guard with first_mismatched_field=frozen_durable_write_context_hash.

PHASE 7 ROLLBACK / PARTIAL-WRITE COVERAGE

      l4_state_receipt_digest emitted, then mismatch at

        - replay snapshot reflects no new entry
        - retrieval/cache invalidation NOT performed

R-3   mismatch_at_invalidation_only:
      All earlier stages match; mismatch detected only at
      retrieval_cache_invalidation_digest. Test asserts:
        - L4 state retained (committed=true at L4 layer)
        - rollback_required=true at projection layer only
        - Out-of-band reconciliation log emitted with trace_id

PHASE 8 OTEL ASSERTION SHAPE
------------------------------------------------------------------------------------------------------------------------
For every test row, the OTEL exporter under test MUST surface:
  - exactly one uwg.write.context.frozen span per attempt
  - one uwg.write.stage.emit span per emitted stage
  - exactly one uwg.write.compare span per attempt
  - at most one uwg.write.committed span per attempt (zero on mismatch
    detected before l4_state_receipt; one on mismatch detected after
    l4_state_receipt with rollback_required=true)
  - exactly one uwg.write.blocked span on mismatch (zero on full match)

Tests MUST verify span attributes, not just span names. Idempotency
replays MUST surface idempotency_replay=true on the uwg.write.committed
span.

PHASE 9 COVERAGE MATRIX ROW SCHEMA
