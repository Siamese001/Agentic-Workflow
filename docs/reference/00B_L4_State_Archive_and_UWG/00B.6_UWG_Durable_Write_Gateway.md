PHASE 2 UWG VALIDATION PIPELINE
------------------------------------------------------------------------------------------------------------------------
Required pipeline:

1. Receive CommitRequest
- Accept only CommitRequest from Exit.
- Reject requests from L2, L6, HITL, C0, L5, tools, connectors, models, PTC sandbox, or scripts.
- Verify request_id, run_id, trace_root, tenant_id, policy_hash, blueprint_hash, replay_key.

2. Verify authority and source
- cleared ExitReviewPacket exists.
- GateVerdict refs exist where required.
- L5CertificationResult refs exist where required.
- HITL reclearance refs exist when needed.
- route_contract_ref and execution lineage match.

3. Validate StateDiff
- target_surface known.
- operation_type allowed for target surface.
- before_ref resolves.
- after_candidate validates against schema_ref.
- validation_rules pass.
- policy_refs active.
- blast_radius bounded.
- rollback_plan_ref valid where required.

4. Validate replay/audit
- replay_key present.
- snapshot current.
- deterministic digest stable.
- audit ledger available.

5. Acquire write lock
- lock target surfaces.
- fail on contention unless retry policy explicitly allowed.
- do not partially commit without lock.

6. Apply atomic commit
- use transaction semantics.
- no in-place mutation when version_insert or alias_swap required.
- produce snapshot_after.
- emit commit receipt.

7. Trigger refresh + audit
- produce read-surface refresh plan/ref.
- append audit ledger.
- release lock after receipt chain is durable.
