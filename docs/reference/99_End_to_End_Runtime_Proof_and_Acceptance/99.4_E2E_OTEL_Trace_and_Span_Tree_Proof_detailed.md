OBJECTIVE
------------------------------------------------------------------------------------------------------------------------
Prove the runtime emitted inspectable OpenTelemetry-style traces and that the trace tree matches the actual route path.

TRACE TREE REQUIREMENTS
------------------------------------------------------------------------------------------------------------------------
Required root attributes:
- trace_root
- request_id
- run_id
- tenant_id
- policy_hash
- blueprint_hash
- replay_key
- route_id if route emitted
- risk_tier
- execution_form

EXPECTED SPAN NAMES
------------------------------------------------------------------------------------------------------------------------
- intake.validate_envelope
- intake.bind_identity_session
- l1.parse_intent
- l1.emit_plan_contract
- l0.route.select
- l0.route.emit_contract
- c0.plan if grounding required
- c0.fetch if grounding required
- c0.graph if graph required
- c0.shape if grounding required
- c0.contract if grounding required
- prompt_assembly.load_bom if prompt used
- prompt_assembly.compose_slots if prompt used
- prompt_assembly.emit_artifact if prompt used
- l3.workflow.build if managed workflow
- l3.step.dispatch if managed workflow
- l2.e1.prep
- l2.e2.valid
- l2.e3.exec
- l2.e4.heal if repair attempted
- l2.e5.seal
- exit.normalize
- exit.evaluate
- exit.disposition
- uwg.validate if commit requested
- uwg.commit if commit accepted
- l6.ingest after runtime boundary

TRACE VALIDATION RULES
------------------------------------------------------------------------------------------------------------------------
- Parent span IDs must form a valid tree or DAG-consistent trace graph.
- Bypassed layers must not show false-positive execution spans.
- All tool/model/script calls must include provider/tool/model ID, latency, token/cost where applicable, status, and error fields.
- All side-effect spans must include capability_token_ref and sandbox_envelope_ref.
- All grounded answer spans must include evidence_contract_ref.
- All commit-path spans must include commit_request_id and UWG receipt when accepted.

FAIL CONDITIONS
------------------------------------------------------------------------------------------------------------------------
- Missing trace_root.
- Span exists without request_id/run_id linkage.
- Tool/model call lacks provider/tool/model identity.
- L4 write span appears outside UWG.
- L6 span appears before Exit disposition.
- Hidden reroute appears without L0/Exit receipt.
