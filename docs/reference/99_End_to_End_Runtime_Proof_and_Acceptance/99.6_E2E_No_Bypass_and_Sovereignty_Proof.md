OBJECTIVE
------------------------------------------------------------------------------------------------------------------------
Prove no runtime layer bypasses its authority boundary.

BYPASS ASSERTIONS
------------------------------------------------------------------------------------------------------------------------
- U0 does not reason, retrieve, route, execute, or mutate.
- L1 does not retrieve final evidence, route with authority, execute tools, or write durable state.
- L0 does not retrieve, execute, mutate, or approve final output.
- C0 does not answer, route, execute, mutate, or approve.
- Prompt Assembly does not retrieve, route, execute, or mutate.
- L3 does not re-decide route, execute directly, or commit durable state.
- L2 does not route, expand workflow, ask humans directly, approve final egress, or commit durable state.
- Runtime Gates do not commit durable state or become final Exit disposition.
- Exit does not execute tools, retrieve, mutate L4, or let L6 rescue current run.
- HITL does not become sovereign authority or write directly.
- L5 does not own live runtime dispositions or durable write admission.
- UWG is the only durable write path into L4.
- L6 does not mutate current run or write directly to L4.
- 99 does not own runtime authority. It only proves.

REQUIRED ANTI-BYPASS TESTS
------------------------------------------------------------------------------------------------------------------------
- test_u0_no_retrieval_or_execution
- test_l1_no_tool_or_retrieval_calls
- test_l0_no_execution_or_model_call
- test_c0_no_answer_generation
- test_prompt_assembly_no_fetch
- test_l3_no_route_redecision
- test_l2_no_l4_write
- test_exit_no_l4_mutation
- test_hitl_no_direct_write
- test_l5_no_runtime_disposition_output
- test_l6_no_current_run_mutation
- test_only_uwg_writes_l4
- test_99_no_runtime_side_effects

NO-BYPASS RECEIPT
------------------------------------------------------------------------------------------------------------------------
NoBypassProofReceipt:
- scenario_id

FAIL CONDITIONS
------------------------------------------------------------------------------------------------------------------------
- Any write to L4 outside UWG.
- Any L6 influence before Exit disposition.
- Any prompt/retrieved/human/tool content overwrites authority fields.
- Any hidden reroute without L0/Exit record.
- Any layer emits another layer's canonical contract.
