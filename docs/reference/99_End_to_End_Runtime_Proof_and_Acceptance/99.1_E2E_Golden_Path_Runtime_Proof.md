OBJECTIVE
------------------------------------------------------------------------------------------------------------------------
Prove the simplest governed runtime path works end to end.

Golden path:
U0 validates request -> L1 plans -> L0 routes -> C0 retrieves if needed -> Prompt Assembly packages -> L2 executes ->
Exit disposes -> response returns -> L6 receives sealed exhaust after runtime boundary.

SCENARIO GP-001: GROUNDED READ ANSWER
------------------------------------------------------------------------------------------------------------------------
Input shape:
- User asks a factual question against a known uploaded/reference source.
- Grounding is required.
- No durable write requested.
- No HITL required.

Expected path:
1. 01 U0 Intake emits ValidatedRequest with request_id, session_id, trace_root, tenant baseline.
2. 02 L1 emits L1PlanContract with grounding_required = yes and support_target populated.
3. 03 L0 emits RouteContract with route_id = R3_SIMPLE_GROUNDED_READ and execution_form = SINGLE_STEP.
4. C0 emits RetrievalPlan, CandidateEvidencePool, ShapedEvidenceSet, and FinalEvidenceContract.
5. PA emits PromptEnvelope or CompiledPromptArtifact with retrieved content as data only.
6. 04 L2 emits sealed_l2_artifact and no direct L4 write.
7. 05 Exit emits ExitReviewPacket and exactly one X3 disposition.
8. 06 L6 receives RuntimeExhaustBundle only after runtime boundary.

REQUIRED PROOF ARTIFACTS
------------------------------------------------------------------------------------------------------------------------
- gp_001_request.json
- gp_001_l1_plan.json
- gp_001_route_contract.json
- gp_001_final_evidence_contract.json
- gp_001_prompt_envelope.json
- gp_001_sealed_l2_artifact.json
- gp_001_exit_review_packet.json
- gp_001_x3_disposition.json
- gp_001_otel_trace.json
- gp_001_replay_receipt.json
- gp_001_no_bypass_receipt.json

PASS CONDITIONS
------------------------------------------------------------------------------------------------------------------------
- Each expected artifact exists.
- Every artifact shares request_id, run_id where applicable, trace_root, policy_hash, blueprint_hash, and replay_key.
- Final answer cites or links to evidence refs.
- No unsupported material claims are present.
- No direct writes to L4 occur.
- L6 activity starts only after X3 disposition is sealed.
