99_END_TO_END_RUNTIME_PROOF_AND_ACCEPTANCE
========================================================================================================================

OBJECTIVE
------------------------------------------------------------------------------------------------------------------------
Prove every route family has executable coverage and cannot silently collapse into another path.

ROUTE COVERAGE TABLE
------------------------------------------------------------------------------------------------------------------------
| Route | Required scenario | Expected proof |
|---|---|---|
| R1A_EXACT_CACHE | repeated stable exact request | terminal RET packet, no C0, no PA, no L2 |
| R1B_SEMANTIC_CACHE | reuse-safe similar stable request | calibrated similarity receipt, terminal RET |
| R5_FALLBACK | unsafe, unsupported, or unclear ask | safe abstain or clarify RET packet |
| R3_SIMPLE_GROUNDED_READ | factual source-backed answer | C0 -> PA -> one L2 -> Exit, no L3 |
| R4_SINGLE_ACTION | one reversible bounded action | one L2 action artifact, no L3, optional UWG only |
| R3_PLUS_R4_SINGLE_STEP | action needing bounded argument lookup | C0 grounds args, PA packages, one L2 action |
| R3R4_MANAGED_WORKFLOW | dependent multi-step workflow | L3 DAG, step contracts, L2 per ready node |
| HITL_POSTURE | high-impact or ambiguous mutation | freeze packet, human input as data, L5 re-clear |
| UWG_COMMIT_PATH | authorized durable mutation | Exit CommitRequest, UWG receipt, L4 audit append |

NEGATIVE ROUTE PROOFS
------------------------------------------------------------------------------------------------------------------------
- R1A must fail if freshness expired.
- R1B must fail if factual/current/source-specific support is required.
- R3 simple grounded read must not invoke L3.
- R4 single action must not broaden into multi-step workflow.
- L3 must not re-decide L0 route.
- HITL must not write directly.
- UWG path must not be entered without Exit CommitRequest.

ACCEPTANCE CRITERIA
------------------------------------------------------------------------------------------------------------------------
Route coverage is complete only when each route family has:
- positive scenario
- negative scenario
- expected contracts
- expected trace spans
- expected absent spans
- replay digest
- proof that bypassed layers truly did not run
