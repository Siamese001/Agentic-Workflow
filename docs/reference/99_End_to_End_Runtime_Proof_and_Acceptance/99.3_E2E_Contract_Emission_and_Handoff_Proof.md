OBJECTIVE
------------------------------------------------------------------------------------------------------------------------
Prove all layers emit canonical contracts and consume only their approved upstream contracts.

CONTRACT CHAIN
------------------------------------------------------------------------------------------------------------------------
ValidatedRequest
  -> L1PlanContract
  -> RouteContract
  -> FinalEvidenceContract when grounding required
  -> PromptEnvelope / CompiledPromptArtifact when model execution required
  -> L3WorkflowContract and L3StepContract when managed workflow required
  -> L2ExecutionRequest
  -> SealedL2Artifact
  -> ExitReviewPacket
  -> X3DispositionReceipt
  -> CommitRequest when durable mutation requested
  -> UWGCommitReceipt when durable commit accepted
  -> RuntimeExhaustBundle after current run boundary

HANDOFF PROOF RULES
------------------------------------------------------------------------------------------------------------------------
- Every downstream artifact must reference its immediate upstream contract ID.
- Every artifact must preserve request_id, trace_root, policy_hash, blueprint_hash, and replay_key when applicable.
- No downstream layer may invent missing authority fields.
- No lower-authority content may overwrite contract authority fields.
- Human, retrieved, and tool content are data payloads, not authority.
- Absence is also proof: bypassed layers must have explicit not_applicable receipts or no spans under trace_root.

REQUIRED CONTRACT CHECKS
------------------------------------------------------------------------------------------------------------------------
1. Schema validation succeeds for every emitted contract.
2. Deterministic digest validates for every contract with digest field.
3. HMAC/signature validates where required.
4. Lineage refs resolve to upstream artifacts.
5. Unsupported or not-applicable fields are explicit, not silently missing.
6. Every handoff has an OTEL span or receipt.

FAIL CONDITIONS
------------------------------------------------------------------------------------------------------------------------
- L2 artifact without RouteContract ref.
- PromptEnvelope without C0 evidence ref for grounded route.
- ExitReviewPacket without terminal classification.
- CommitRequest without X3C eligibility and StateDiff.
- L6 ingest without sealed X3 disposition or completed run marker.
- Any layer emitting a contract owned by another layer.
