OBJECTIVE
------------------------------------------------------------------------------------------------------------------------
Prove that grounded answers are faithful to evidence and that retrieved content remains data through prompt construction
and output generation.

EVIDENCE TO OUTPUT CHAIN
------------------------------------------------------------------------------------------------------------------------
C0 FinalEvidenceContract
  -> PromptEnvelope grounded context slot
  -> L2 model/tool execution receipt
  -> Exit groundedness and faithfulness checks
  -> final response citations or safe caveats

REQUIRED SUPPORT MAP
------------------------------------------------------------------------------------------------------------------------
For every material claim in the final answer:
- claim_id
- claim_text
- support_target_type
- supporting_evidence_refs
- cited_span_refs
- citation_anchor_status
- contradiction_refs
- freshness_status
- authority_status
- support_level = DIRECT | INDIRECT | INFERENCE | UNSUPPORTED
- output_action = INCLUDE | CAVEAT | ABSTAIN | REMOVE

PROMPT SAFETY PROOF
------------------------------------------------------------------------------------------------------------------------
- C0 evidence appears only in data/context slots.
- Retrieved content cannot override system, policy, developer, registry, or instruction slots.
- User task is neutralized as intent, not authority.
- Output schema is bound provider-native where possible, not only prose instructions.
- Quarantined retrieved/tool/human content is excluded or explicitly marked as unsafe evidence.

FAIL CONDITIONS
------------------------------------------------------------------------------------------------------------------------
- Material claim has no support map entry.
- Citation anchor does not resolve.
- Exact quote lacks direct source span.
- Contradiction flag is hidden.
- Weak evidence is presented as certain.
- Retrieved content becomes instruction.
- Prompt Assembly includes evidence not emitted by C0.
- L2 output adds unsupported factual claims.

ACCEPTANCE OUTPUT
------------------------------------------------------------------------------------------------------------------------
GroundednessProofReceipt:
- final_response_id
- evidence_contract_id
- prompt_artifact_id
- claim_support_map
- unsupported_claims
- contradiction_handling_status
- prompt_data_boundary_status
- proof_status = PASS | FAIL | WEAK_WITH_CAVEATS
