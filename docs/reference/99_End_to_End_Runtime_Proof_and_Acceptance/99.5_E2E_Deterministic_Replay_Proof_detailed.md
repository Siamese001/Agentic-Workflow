OBJECTIVE
------------------------------------------------------------------------------------------------------------------------
Prove deterministic replay surfaces are bound and comparable.

REPLAY INPUTS
------------------------------------------------------------------------------------------------------------------------
Each replay-certified run must bind:
- normalized_request_hash
- input_hash
- prompt_hash if prompt used
- route_digest
- evidence_contract_hash if grounding used
- policy_hash
- blueprint_hash
- snapshot_manifest
- environment_digest
- tool_registry_digest
- model_registry_digest
- provider_lane
- replay_key

REPLAY MODES
------------------------------------------------------------------------------------------------------------------------
1. Route replay
   Same ValidatedRequest + same L1PlanContract + same policy/snapshot must produce same RouteContract digest.

2. Evidence replay
   Same RetrievalPlan + same L4 retrieval snapshot must produce equivalent FinalEvidenceContract hash or explained drift.

3. Prompt replay
   Same BOM + same FinalEvidenceContract + same schema must produce same CompiledPromptArtifact hash.

4. Execution replay
   Same work order + same sandbox + same deterministic tool/model snapshot must produce same sealed artifact digest or classified nondeterminism.

5. Exit replay
   Same sealed artifact + same policy/gate inputs must produce same X3 disposition.

6. Commit replay
   Same CommitRequest + same L4 before_snapshot must produce same UWG validation result and commit digest.

ACCEPTANCE OUTPUT
------------------------------------------------------------------------------------------------------------------------
ReplayComparisonReceipt:
- replay_id
- original_run_id
- replay_run_id
- replay_scope
- input_digest_match
- route_digest_match
- evidence_digest_match
- prompt_digest_match
- execution_digest_match
- exit_digest_match
- commit_digest_match if applicable
- nondeterminism_flags
- accepted_variance
- replay_status = PASS | FAIL | EXPLAINED_VARIANCE | NOT_APPLICABLE

FAIL CONDITIONS
------------------------------------------------------------------------------------------------------------------------
- Missing replay_key.
- Missing snapshot_manifest.
- Wall-clock value affects decision.
- Raw entropy affects decision.
- Mixed state reads detected.
- Provider drift unclassified.
- Replay failure cannot localize to layer or span.
