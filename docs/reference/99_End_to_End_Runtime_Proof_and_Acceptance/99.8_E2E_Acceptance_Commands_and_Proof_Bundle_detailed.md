OBJECTIVE
------------------------------------------------------------------------------------------------------------------------
Define executable proof commands, proof bundle outputs, CI targets, and failure triage for the 99 proof harness.

RECOMMENDED COMMAND SURFACES
------------------------------------------------------------------------------------------------------------------------
These commands are logical targets. Windsurf must map them to existing repo conventions instead of inventing parallel runners
when canonical scripts already exist.

1. Full E2E proof suite
python -m tests.e2e.run_agentic_runtime_proof --scenario-set all --emit-proof-bundle artifacts/e2e/latest

2. Golden path only
python -m tests.e2e.run_agentic_runtime_proof --scenario GP-001 --emit-proof-bundle artifacts/e2e/gp_001

3. Route coverage
python -m tests.e2e.run_route_coverage_proof --all-routes --emit-proof-bundle artifacts/e2e/routes

4. OTEL trace proof
python -m tests.e2e.validate_trace_tree --proof-bundle artifacts/e2e/latest

5. Replay proof
python -m tests.e2e.validate_replay --proof-bundle artifacts/e2e/latest --strict

6. No-bypass proof
python -m tests.e2e.validate_no_bypass --proof-bundle artifacts/e2e/latest

7. Groundedness proof
python -m tests.e2e.validate_grounded_output --proof-bundle artifacts/e2e/latest

PROOF BUNDLE SCHEMA
------------------------------------------------------------------------------------------------------------------------
E2EProofBundle:
- bundle_id
- generated_at
- repo_commit
- scenario_set
- policy_hash
- blueprint_hash
- registry_digest
- tests_run
- scenarios
  - scenario_id
  - scenario_status
  - expected_path
  - observed_path
  - contracts
  - traces
  - replay_receipts
  - no_bypass_receipts
  - groundedness_receipts
  - disposition_receipts
  - uwg_receipts
  - l6_exhaust_receipts
- failure_summary
- acceptance_status = PASS | FAIL | PARTIAL

CI ACCEPTANCE GATES
------------------------------------------------------------------------------------------------------------------------
- e2e_golden_path_proof must pass before merge.
- e2e_route_coverage_proof must pass before release.
- e2e_no_bypass_proof must pass before release.
- e2e_replay_proof must pass for replay-certified paths.
- e2e_groundedness_proof must pass for grounded answer paths.
- e2e_uwg_commit_proof must pass for durable write paths.
- e2e_l6_firewall_proof must pass before enabling learning promotions.

FAILURE TRIAGE MAP
------------------------------------------------------------------------------------------------------------------------
- Missing ValidatedRequest -> 01 owner.
- Missing L1PlanContract -> 02 owner.
- Missing or nondeterministic RouteContract -> 03 owner.
- Missing FinalEvidenceContract -> C0 owner.
- Missing PromptEnvelope -> PA owner.
- Missing SealedL2Artifact -> 04 owner.
- Missing GateVerdict law or malformed verdict -> 00C owner.
- Missing X3 disposition -> 05 owner.
- Missing UWG receipt for commit path -> 00B owner.
- L5 certification gap -> 00A owner.
- L6 pre-boundary mutation -> 06 owner.
- Trace tree cannot prove path -> 99.4 plus local span owner.
- Replay cannot localize failure -> 99.5 plus layer that owns mismatched digest.

ACCEPTANCE CRITERIA
------------------------------------------------------------------------------------------------------------------------
99 is complete only when:
1. It can run at least one golden path scenario.
2. It can prove every route family or mark unavailable route families with explicit reason.
3. It emits a proof bundle with contracts, traces, replay, no-bypass, groundedness, and disposition receipts.
4. It fails closed on missing trace, missing replay, missing contract, unauthorized write, or unsupported claim.
5. It maps every failure to a canonical owner.
6. It never acts as runtime authority itself.
