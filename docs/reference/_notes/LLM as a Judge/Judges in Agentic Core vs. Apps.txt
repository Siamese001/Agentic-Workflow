-------------------|------------------------------------------------|---------------------------------------------|--------------------------------------|-------------------------------

                   | lowest viable agency                           | or heuristic checks                         |                                      | DON’T: choose route
-------------------|------------------------------------------------|---------------------------------------------|--------------------------------------|-------------------------------
L0 ROUTE           | Route consistency with plan, cheapest-safe     | Mostly deterministic; shadow LLM judge      | Core                                 | DO: audit route choice
                   | path, HITL posture                             | allowed (non-authoritative)                 |                                      | DON’T: override route authority
-------------------|------------------------------------------------|---------------------------------------------|--------------------------------------|-------------------------------
C0 EVIDENCE        | Recall, precision, contradiction, support,     | LLM judge via PA → L2 → Gateway;            | Core infra + App rubric              | DO: score evidence quality
                   | citation integrity                             | plus heuristics (BM25/dense checks)         |                                      | DON’T: retrieve/answer
-------------------|------------------------------------------------|---------------------------------------------|--------------------------------------|-------------------------------

-------------------|------------------------------------------------|---------------------------------------------|--------------------------------------|-------------------------------

=============================================================================================================
CORE vs apps_* SPLIT
=============================================================================================================

CONCERN                    | agentic_core (HOW judging runs)                  | apps_* (WHAT good means)
---------------------------|--------------------------------------------------|-----------------------------------------------
Invocation & dispatch      | JudgeRunner, Gateway routing, retries           | Configure model/heuristic use
Prompt artifact            | PA → CompiledPromptArtifact discipline           | Domain prompt sections
Parsing & schema           | JudgeResult (score, rationale, receipts)         | Optional extensions / scorecard mapping
Telemetry & replay         | OTEL spans, manifests, replay keys              | Use for app reports
Calibration framework      | Reliability metrics, comparison harness          | Provide holdout labels & datasets
Rubrics & dimensions       | Generic hooks                                   | Domain-specific dimensions (e.g., recall, fairness)
Thresholds                 | Defaults                                        | App-specific thresholds
Examples/fixtures          | None                                            | Domain examples, gold data

ANTI-PATTERN (DO NOT DO)
------------------------
[ apps_* judge ] -> raw prompt -> direct provider/gateway call -> unsealed score


=============================================================================================================
RUNTIME vs SHADOW JUDGES
=============================================================================================================

TYPE            | PURPOSE                         | PROPERTIES
----------------|----------------------------------|-----------------------------------------------
Runtime judges  | Protect current run              | Fast, bounded, fail-closed, no learning
Shadow (L6)     | Improve future runs              | Deeper analysis, calibration, no current-run effect


=============================================================================================================
FINAL RULE
=============================================================================================================

- Use agentic_core for judge infrastructure.
- Use apps_* for domain judgment.
- Judges exist across the spine, but remain evaluation overlays.
- Owning layer makes the decision; Exit emits X3; UWG commits; L6 learns.
