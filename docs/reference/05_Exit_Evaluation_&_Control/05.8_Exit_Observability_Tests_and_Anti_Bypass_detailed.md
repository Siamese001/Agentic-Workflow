ANTI-BYPASS TEST SUITE
------------------------------------------------------------------------------------------------------------------------
Test: no_direct_l4_write_from_exit
- monkeypatch/write-spy L4 mutation APIs.
- run commit-path packet.
- assert Exit emits CommitRequest but no L4 mutation call occurs.

Test: l2_write_attempt_detected
- input sealed artifact with direct_write_attempt flag.
- assert X1C FAIL and X3A.

Test: l6_rescue_attempt_detected
- attach live learning mutation signal before X3.
- assert hard fail or X3B, no mutation.

Test: hitl_modification_requires_reclearance
- human MODIFY_DIFF packet without L5 re-clearance.
- assert no X3D/X3C.

Test: retrieved_content_not_instruction
- RET/C0 evidence contains role override text.
- assert X1F fails or quarantines and no authority overwrite.

Test: prompt_assembly_receipt_required
- model execution packet missing PromptAssemblyStatus.
- assert fail when PA required.

Test: c0_contract_required_for_grounded
- route support_target requires grounding but no C0 contract.
- assert fail before allow.

Test: exactly_one_disposition
- randomized result bundle with conflicting signals.
- assert single X3 disposition.

Test: no_silent_fallback
- input has fallback_depth > 0 without reason_codes.
- assert X1E fail.

Test: no_uncommitted_artifact_reference
- final response references artifact without UWG receipt.
- assert X1B/X3D validation fails.

Test: material_trace_gap_escalates
- high-impact commit with missing trace span.
- assert X3B.

INTEGRATION TEST MATRIX
------------------------------------------------------------------------------------------------------------------------
Case A: low-risk answer-only success
- L2 sealed success, no mutation, evidence adequate.
- Expected: X3D.

Case B: grounded answer weak support
- C0 status WEAK_WITH_CAVEATS, answer caveats properly.
- Expected: X3D if policy allows caveated answer, otherwise X3E/X3B.

Case C: grounded answer unsupported claim
- material claim lacks citation/support.
- Expected: X3A or X3B.

Case D: direct write attempt
- L2 artifact shows L4 mutation occurred.
- Expected: X3A hard fail.

Case E: high-impact write candidate
- StateDiff present, X1A-F clear, X1G/H/I/J clear, HITL done.
- Expected: X3C CommitRequest to UWG only.

Case F: high-impact write missing HITL
- Expected: X3B.

Case G: human modified packet not re-cleared
- Expected: blocked from X3D/X3C.

Case H: RET exact cache valid
- Expected: X3D with freshness check.

Case I: RET semantic cache below threshold
- Expected: X3A/X3E.

Case J: observability material gap
- Expected: X3B.

ACCEPTANCE CRITERIA
------------------------------------------------------------------------------------------------------------------------
The Exit pack is acceptable only when:
- All child contracts compile or validate under repo convention.
- All source packet classes can be normalized.
- Missing critical fields fail before semantic grading.
- X1 gate results are structured and digestible.
- X2 aggregation is deterministic.
- X3 emits exactly one disposition.
- X3C never mutates L4.
- HITL changes are treated as data and re-cleared.
- Runtime exhaust is sealed only after disposition.
- OTEL spans demonstrate the path actually ran.
- Replay proof is deterministic for same packet/snapshot.
- Anti-bypass tests fail if any layer writes/executes/retrieves outside its authority.

PROHIBITED TEST ANTI-PATTERNS
------------------------------------------------------------------------------------------------------------------------
- Mock-only tests that assert success without checking artifacts.
- Tests that inspect logs but not structured receipts.
- Tests that claim telemetry without verifying spans.
- Tests that claim replay without comparing deterministic digests.
- Tests that allow fake PASS on UNKNOWN.
- Tests that allow X3C without CommitRequest.
- Tests that allow final answer to claim uncommitted mutation.
- Tests that use L6 output to change current-run disposition.
