PHASE 2 PIPELINE
------------------------------------------------------------------------------------------------------------------------
Public entrypoint:

bind_identity_scope(transport_result, identity_policy) -> IdentityBaselineResult

Required steps:
1. Read TransportEnvelopeReceipt.
2. Extract identity evidence from approved metadata only.
3. Classify auth mode and principal type.
4. Bind tenant baseline.
5. Bind or create session baseline.
6. Bind region and data residency hint.
7. Produce CallerScopeBaseline.
8. If identity or tenant cannot be safely established, emit identity-baseline rejection.

Hard no:
- No deep resource authorization.
- No retrieval of user files.
- No memory reads beyond session existence check if already part of intake infrastructure.
- No route recommendation.
- No prompt construction.
- No tool/model capability grant.
