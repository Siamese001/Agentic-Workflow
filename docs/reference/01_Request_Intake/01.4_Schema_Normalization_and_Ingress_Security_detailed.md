PHASE 2 PIPELINE
------------------------------------------------------------------------------------------------------------------------
Public entrypoint:

validate_and_normalize_payload(entry_control_result, schema_registry, ingress_security_policy) -> SchemaNormalizationResult

Required steps:
1. Load request schema.
2. Parse body according to accepted content type.
3. Validate required fields.
4. Normalize text, structured fields, attachment refs, URLs, and file refs.
5. Preserve raw payload hash and body ref.
6. Attach origin and authority labels to payload segments.
7. Detect ingress security findings as evidence.
8. Emit RequestSchemaValidationReceipt, NormalizedUserPayload, and IngressOriginLabelManifest.
9. If schema or structural security fails closed, prepare rejection candidate for 01.6.

Hard no:
- No semantic planning.
- No generated answer.
- No C0 retrieval.
- No Prompt Assembly slot construction.
- No L5 certification claim.
- No Runtime Gate disposition claim.
