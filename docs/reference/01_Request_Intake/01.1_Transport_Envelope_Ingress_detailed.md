PHASE 2 PIPELINE
------------------------------------------------------------------------------------------------------------------------
Public entrypoint:

validate_transport_envelope(raw_input, transport_policy) -> TransportEnvelopeResult

Required steps:
1. Classify transport and channel.
2. Validate transport allowlist.
3. Validate method / operation shape.
4. Validate content type and encoding.
5. Capture raw body reference and raw payload hash.
6. Inventory attachment handles without reading their semantic content.
7. Enforce transport-level size limit.
8. Emit TransportEnvelopeReceipt.
9. If malformed, emit MalformedEnvelopeReport and stop.

Hard no:
- No model calls.
- No tool calls.
- No identity lookup beyond transport metadata capture.
- No semantic classification.
- No route recommendation.
- No durable writes.
