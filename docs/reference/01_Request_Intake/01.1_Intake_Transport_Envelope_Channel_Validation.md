"Did the request arrive through an accepted channel, in an admissible envelope, within size and shape limits?"

REQUIRED CHECKS
========================================================================================================================
T1 Accepted channel
- Verify channel is one of the configured accepted runtime ingress channels.
- Reject unknown raw channels unless explicitly routed through a safe import adapter.
- Preserve raw channel metadata without trusting it as authority.

T2 Envelope shape
- Verify payload container is parseable enough for structural handling.
- Verify required transport fields are present or explicitly unknown.
- Verify attachment and connector references are serialized and bounded.

T3 Size and quota floor
- Enforce max request byte count.
- Enforce max attachment count.
- Enforce max per-attachment size.
- Enforce max total attachment size.
- Enforce max connector handle count.

T4 Encoding and normalization safety
- Reject undecodable payloads.
- Normalize newline and encoding safely.
- Preserve original payload ref for audit.
- Do not rewrite user meaning.

T5 No execution
- Treat all inbound bytes as inert.
- Do not render HTML.
- Do not execute markdown, code blocks, URLs, shell fragments, document macros, or connector handles.
- Do not fetch URLs.
- Do not inspect attachment contents beyond admission metadata unless an explicit safe parser exists inside intake scope.

OUTPUT RULES
