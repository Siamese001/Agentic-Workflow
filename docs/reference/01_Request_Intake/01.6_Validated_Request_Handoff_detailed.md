PHASE 2 PIPELINE
------------------------------------------------------------------------------------------------------------------------
Public entrypoint:

finalize_intake_handoff(stage_results) -> IntakeFinalResult

Required steps:
1. Collect child stage receipts from 01.1 through 01.5.
2. Identify first failure, if any.
3. If failure exists, emit RejectedRequest and IntakeAuditReceipt.
4. If no failure exists, validate handoff completeness.
5. Emit ValidatedRequest.
6. Wrap ValidatedRequest in L1HandoffEnvelope.
7. Emit no-raw-bypass assertion.
8. Send only the handoff envelope to L1.

- No durable write.
