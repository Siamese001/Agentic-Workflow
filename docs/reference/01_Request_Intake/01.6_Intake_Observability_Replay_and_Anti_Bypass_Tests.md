INTAKE REPLAY RULES
========================================================================================================================
Replay for U0 means:
- same raw payload
- same channel policy snapshot
- same identity/tenant/session inputs
- same quota state snapshot or mocked quota snapshot
- same schema version
- same normalization ruleset
- same origin-label ruleset

Must reproduce:
- same normalized_request_hash
- same idempotency_key
- same schema status
- same origin label digest
- same admission decision
- same rejection stage and reason codes when rejected

Must not depend on:
- uncontrolled wall clock
- random UUID in deterministic digest
- mutable quota state without snapshot
- ambient identity state without snapshot
- network calls
- downstream route/model/tool behavior

ANTI-BYPASS TESTS
========================================================================================================================
Tests must fail if:
- L1 can be invoked without ValidatedRequest.
- malformed transport reaches L1.
- L0 can receive raw U0 payload directly.
- C0 can retrieve from raw U0 payload directly.
- Prompt Assembly can consume raw U0 payload without ValidatedRequest and L1/L0/C0 pathway.
- L2 can execute directly from U0.
- U0 emits RouteContract.
- U0 emits FinalEvidenceContract.
- U0 emits PromptEnvelope.
- U0 emits SealedL2Artifact.
- U0 emits ExitDisposition.
- U0 writes L4 or calls UWG.
- U0 calls a model.
- U0 calls a tool.
- U0 fetches URL content.
- U0 dereferences connector content.
- U0 accepts caller-supplied request_id over system-issued request_id.
- U0 drops origin labels for quoted or suspicious content.
- U0 replay digest changes for equivalent normalized payload.
