PHASE 2 PIPELINE
------------------------------------------------------------------------------------------------------------------------
Public entrypoint:

enforce_entry_controls(identity_result, quota_policy, dedupe_store) -> EntryControlResult

Required steps:
1. Load entry quota policy.
2. Check request size and attachment count.
3. Check tenant/principal/session rate limits.
4. Compute duplicate fingerprint.
5. Check dedupe window.
6. Emit QuotaReceipt and DuplicateSuppressionReceipt.
7. If blocked, emit RejectedRequest candidate for 01.6 to finalize.

Hard no:
- No L0 route budget estimation.
- No provider token-cost forecast beyond rough entry size if existing utility provides it.
- No model/tool call.
- No semantic dedupe using embeddings.
- No durable user memory update.
- No unapproved quota ledger write outside existing quota subsystem.
