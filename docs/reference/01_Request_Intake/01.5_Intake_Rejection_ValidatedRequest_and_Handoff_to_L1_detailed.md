OBJECTIVE
========================================================================================================================
Emit exactly one U0 outcome:
- ValidatedRequest handed to L1, or
- RejectedRequest with safe structural reason.

DATA CONTRACTS
========================================================================================================================
1. IntakeAdmissionDecision
Fields:
- admission_decision_id
- request_id
- trace_root
- decision = VALIDATED | REJECTED
- decisive_stage
- decisive_reason_codes[]
- structural_admissibility_status
- downstream_allowed
- created_at

2. ValidatedRequestContract
Required fields:
- request_id
- session_id
- trace_root
- tenant_id optional with tenant_status
- caller_scope_baseline
- tenant_session_binding
- normalized_payload
- request_schema_receipt_ref
- quota_receipt_ref
- origin_trust_label_set_ref
- data_boundary_map_ref
- injection_triage_receipt_ref
- normalized_request_hash
- idempotency_key
- intake_policy_snapshot_ref
- handoff_target = 02_L1_REASONING_PLAN
- no_reasoning_performed = true
- no_routing_performed = true
- no_retrieval_performed = true
- no_execution_performed = true
- no_write_performed = true

3. RejectedRequestContract
Required fields:
- rejection_id
- request_id if available
- trace_root if available
- rejection_stage
- reason_codes[]
- safe_user_message
- retryable
- missing_or_invalid_fields[]
- quota_status optional
- schema_status optional
- channel_status optional
- security_status optional
- downstream_allowed = false
- no_downstream_runtime_started = true

4. L1HandoffReceipt
Fields:
- handoff_receipt_id
- request_id
- trace_root
- source_surface = 01_REQUEST_INTAKE
- target_surface = 02_L1_REASONING_PLAN
- validated_request_digest
- handoff_time
- handoff_status = SENT | BLOCKED
- block_reason_codes[]

REQUIRED CHECKS
========================================================================================================================
H1 All required receipts present
- Channel receipt
- Caller/tenant/session/quota receipt
- Schema/normalization receipt
- Origin/data-boundary receipt

H2 No downstream work already occurred
- Confirm no route_id exists.
- Confirm no evidence contract exists.
- Confirm no prompt envelope exists.
- Confirm no tool/model invocation exists.
- Confirm no state diff exists.
- Confirm no L4 write exists.

H3 L1 input completeness
- Ensure L1 receives validated_request, request_id, session_id, trace_root, caller_scope_baseline, tenant binding,
  normalized payload, origin labels, visible context refs, source handles, freshness hints if explicitly present,
  and output channel expectations if structurally available.

H4 Safe rejection
- Rejection message must not leak system policy, raw credentials, internal traces, hidden rules, or stack details.
- Rejection should be specific enough for safe retry when retryable.

H5 Single outcome
- Emit exactly one of ValidatedRequest or RejectedRequest.
- Never emit both.
- Never silently drop invalid request.

OUTPUT RULES
========================================================================================================================
VALIDATED:
- emit ValidatedRequestContract
- emit L1HandoffReceipt
- call or enqueue L1 handoff according to runtime architecture

REJECTED:
- emit RejectedRequestContract
- emit blocked L1HandoffReceipt if applicable
- return safe structural rejection

REJECTION STAGES
========================================================================================================================
- TRANSPORT_ENVELOPE
- IDENTITY_TENANT_SESSION_QUOTA
- SCHEMA_NORMALIZATION
- ORIGIN_TRUST_TRIAGE
- ADMISSION_ASSEMBLY

OTEL SPANS
========================================================================================================================
Emit:

Required attributes:

- rejection_stage if any

TEST REQUIREMENTS
========================================================================================================================
Tests must fail if:
- both ValidatedRequest and RejectedRequest are emitted
- rejected request reaches L1
- ValidatedRequest lacks request_id/session_id/trace_root
- ValidatedRequest lacks caller_scope_baseline
- ValidatedRequest lacks normalized_payload
- U0 produces route_id or plan fields
- U0 output contains tool/model/evidence artifacts
- rejection leaks secrets or internal policy text

ACCEPTANCE CRITERIA
========================================================================================================================
01.5 is complete when L1 receives only structurally valid, traceable, bounded requests and every invalid request fails
closed with a safe rejection contract.
