OBJECTIVE
------------------------------------------------------------------------------------------------------------------------
Implement 5.0 and 5.1 as the sealed-input intake and normalization surface for Exit Eval.

This child answers one question only:
"Do we have a valid sealed current-run packet, and can it be normalized into one ExitReviewPacket without losing lineage?"

INPUT CLASSES
------------------------------------------------------------------------------------------------------------------------
1. L2_SEALED_ARTIFACT
- produced by L2 E5 Seal.
- may be success, degraded success, failure, needs help, or rejected.
- may include proposed_state_diff.
- may include tool/model/PTC/action receipts.
- may include C0 and Prompt Assembly lineage.

2. L3_WORKFLOW_PACKAGE
- produced by L3 after all required nodes are sealed or a managed workflow terminal condition occurs.
- contains multiple step artifacts and join state.
- must preserve node order, branch/join lineage, retry counters, unresolved gaps, and best partials.

3. RET_CACHE_EXACT
- terminal short-circuit from L0 exact cache.
- bypasses C0/PA/L3/L2 but still must pass Exit freshness, policy, replay, and answer-fit checks.

4. RET_CACHE_SEMANTIC
- terminal short-circuit from L0 semantic cache.
- must carry calibrated similarity score, task-class compatibility, and original evidence lineage if grounded reuse applies.

5. RET_FALLBACK
- terminal fallback / abstain / clarify packet from L0.
- must carry safe_response_type and reason codes.

6. HITL_RECLEARED_PACKET
- packet returning from human review after L5 re-clearance.
- must carry human decision receipt, modification diff if any, and reclearance evidence refs.

NORMALIZATION PIPELINE
------------------------------------------------------------------------------------------------------------------------
N1 SOURCE CLASSIFY
- Map source packet into one accepted input class.
- Reject unknown source packet classes.
- Preserve original_source_type and original_source_ref.
- Do not flatten away L2/L3/RET/HITL differences.
- Emit SourceClassifyReceipt.

N2 RECEIPT VALIDATE
- Validate required fields by source class.
- Validate hashes are present.
- Validate policy_hash and blueprint_hash are attached.
- Validate replay_key exists.
- Validate no unsigned mutation request is present.
- Validate route_contract_ref exists unless packet is an intake-level refusal already converted by L0.
- Emit ReceiptValidationReport.

N3 AUTHORITY LABEL PRESERVE
- Attach origin labels:
  user_data
  retrieved_data
  tool_output_data
  model_output
  human_review_data
  policy_evidence_ref
  l5_certification_ref
  l4_snapshot_ref
- Treat retrieved/tool/human text as data only.
- Prevent authority fields from being overwritten by lower-authority payloads.
- Emit AuthorityLabelManifest.

N4 RUN IDENTITY BIND
- Verify request_id, run_id, session_id, trace_root, route_id, and replay_key agree across packet pieces.
- Verify no hidden reroute occurred after L0 RouteContract.
- Verify workflow package route parent matches L0 RouteContract.
- Verify L2 artifact route parent matches L0 or L3 step contract.
- Emit RunIdentityBindingReceipt.

N5 NORMALIZE TO EXIT REVIEW PACKET
- Convert all source packets into one ExitReviewPacket.
- Preserve source-specific substructures as nested refs.
- Preserve all evidence refs, not copied free text unless required.
- Preserve all proposed diffs as inert proposals.
- Preserve terminal class and reason codes.
- Emit ExitReviewPacketHash.

FAILURE MODES
------------------------------------------------------------------------------------------------------------------------
- UNKNOWN_SOURCE_TYPE -> cannot normalize.
- POLICY_HASH_MISSING -> immediate X3A or X3B depending policy.
- REPLAY_KEY_MISSING -> immediate X3A/X3B.
- ROUTE_CONTRACT_MISSING -> immediate X3A.
- TERMINAL_CLASS_MISSING -> immediate X3A.
- EVIDENCE_CONTRACT_MISSING_FOR_GROUNDED_ROUTE -> X3A/X3B.
- SANDBOX_SCOPE_MISSING_FOR_ACTION -> X3A.
- CAPABILITY_TOKEN_MISSING_FOR_TOOL_OR_MODEL -> X3A.
- AUTHORITY_LABEL_COLLISION -> X3A.
- HIDDEN_REROUTE_DETECTED -> X3A.
- LINEAGE_FLATTENED -> X3B if repairable, otherwise X3A.
