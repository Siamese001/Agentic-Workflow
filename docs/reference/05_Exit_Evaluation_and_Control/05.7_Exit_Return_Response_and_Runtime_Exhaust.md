OBJECTIVE
------------------------------------------------------------------------------------------------------------------------
Implement the safe return and runtime exhaust boundary after X3 disposition.

This child answers one question only:
"What can leave to the caller, what must be sealed as completed-run exhaust, and where does the live runtime boundary end?"

RETURN PAYLOAD RULES
------------------------------------------------------------------------------------------------------------------------
Returned payload may include:
- final_response if X3D.
- safe abstain / clarification if X3E.
- safe partial if X3A permits DENY_SAFE_PARTIAL.
- HITL pending/review status if X3B and policy permits user-visible pending response.
- committed L4 artifact refs only if UWGCommitReceipt exists.
- disposition receipt ID or safe trace/ref where user-visible.
- caveats and unsupported gaps where relevant.
- no hidden state mutation.

Returned payload must not include:
- uncommitted mutation claims.
- quarantined payload content.
- system/developer/policy hidden internals.
- unredacted secrets.
- unsafe tool results.
- unapproved action result.
- raw chain-of-thought or private grader context.
- L6 learning conclusions before after-hours evaluation.
- untrusted human modifications before re-clearance.

X3D ALLOW / FINISH RETURN
------------------------------------------------------------------------------------------------------------------------
ReturnPayload for X3D:
- final_response_ref
- response_schema_status
- evidence_status if grounded
- citation_refs if user-visible
- caveat_refs if support weak but allowed
- commit_receipt_id only if already committed
- disposition_receipt_ref
- trace_root
- runtime_exhaust_manifest_ref

X3E SAFE ABSTAIN / CLARIFY RETURN
------------------------------------------------------------------------------------------------------------------------
ReturnPayload for X3E:
- abstain_reason
- minimal_clarification_question if needed
- safe_alternative_ref if available
- bounded_explanation
- failed_support_target if evidence-related
- no_commit_request assertion
- disposition_receipt_ref
- trace_root

X3A SAFE DENY / REROUTE RETURN
------------------------------------------------------------------------------------------------------------------------
ReturnPayload for X3A:
- safe denial / safe partial / re-entry explanation
- reason category, not raw internal policy dump
- replan_hint if user-visible and safe
- no durable write assertion
- disposition_receipt_ref
- trace_root

X3B HUMAN REVIEW RETURN
------------------------------------------------------------------------------------------------------------------------
ReturnPayload for X3B:
- pending human review / needs review / cannot complete yet message if policy permits.
- no claim that action/write happened.
- no exposure of internal human review packet unless specifically allowed.
- no durable write assertion.
- disposition_receipt_ref
- trace_root

X3C COMMIT REQUEST RETURN
------------------------------------------------------------------------------------------------------------------------
X3C by itself is not final user-facing success unless UWG has completed.

If UWGCommitReceipt exists:
- final response may reference committed artifact.
- attach commit_receipt_id.

If UWGBlockedCommitReceipt exists:
- return safe failure or escalation message.
- do not claim mutation happened.

If UWGHeldCommitReceipt exists:
- return pending/held status if policy permits.
- do not claim mutation happened.

RUNTIME BOUNDARY
------------------------------------------------------------------------------------------------------------------------
The runtime boundary closes after:
- X3 disposition receipt emitted.
- ReturnPayload produced or withheld by policy.
- Commit path response resolved or handed off by policy.
- RuntimeExhaustManifest sealed.

After boundary:
- L6 may ingest sealed exhaust.
- L6 may evaluate, calibrate, RCA, draft proposals, and seek future-run promotion.
- L6 may not mutate the completed current run.
- L6 may not rescue a failed disposition.
- UWG remains the only ink path for future approved learning promotions.
