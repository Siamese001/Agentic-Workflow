OBJECTIVE
------------------------------------------------------------------------------------------------------------------------
Implement X2 aggregation and X3 disposition emission.

This child answers one question only:
"Given the normalized packet and all checkout results, which single current-run disposition is allowed?"

X2 AGGREGATE DECISION MATRIX
------------------------------------------------------------------------------------------------------------------------
Inputs:
- ExitReviewPacket
- X1A-X1F results
- X1G-X1I results
- X1J result if write path active
- HITL receipt if present
- L5 certification refs if required
- live bell signal status
- policy threshold profile
- route risk class
- track label
- materiality classification

Hard fail conditions:
- Any safety breach.
- Any unauthorized mutation.
- Any policy hash mismatch.
- Any system prompt leak.
- Any known prompt injection not neutralized.
- Any direct L4 write attempt outside UWG.
- Any material unsupported claim in grounded answer.
- Any non-replayable high-impact action.
- Any untranscripted PTC IO in commit/high-impact path.
- Any committed artifact reference without UWG receipt.
- Any human modification not re-cleared.

Escalation conditions:
- Human-required by policy.
- High-impact or irreversible action.
- Low confidence on material issue.
- Judge abstained on material quality/safety.
- Evidence conflicted and user impact is material.
- Consistency failed or unknown for commit path.
- Trace gap blocks forensic review.
- Human modification proposed.
- Rollback missing but recoverable.
- Write scope ambiguous but user/HITL could resolve.
- Live bell anomaly indicates suspicious behavior.

Allow conditions:
- Answer-only, no durable mutation.
- X1A-F clear.
- X1H/I clear or policy permits non-material WARN.
- Evidence support adequate or caveated/abstained properly.
- Output schema satisfied.
- No unresolved material safety/policy/authority UNKNOWN.

Commit-request conditions:
- Mutation requested and authorized.
- X1A-F clear.
- X1G clear.
- X1H/I clear.
- X1J clear.
- HITL completed if required.
- L5 certification attached if required.
- CommitRequest complete.
- Next hop is UWG only.

Safe abstain / clarify conditions:
- Missing critical user detail.
- Evidence EMPTY/BLOCKED.
- Weak support where caveat would mislead.
- Unsupported high-impact advice.
- Action scope ambiguous.
- Unsafe or impossible action can be safely explained.

X3 DISPOSITION ENUM
------------------------------------------------------------------------------------------------------------------------
X3A_DENY_REROUTE
- The sealed work cannot safely leave as-is.
- No durable write.
- No hidden retry.
- May include safe partial or bounded re-entry hint.
- Does not itself perform reroute. It issues disposition and re-entry target.

X3B_ESCALATE_HITL
- Freeze and materialize bounded human review packet.
- Human input remains data and must be re-cleared.
- No durable write while under review.

X3C_COMMIT_REQUEST_TO_UWG
- Runtime result is eligible to request durable mutation.
- Exit emits CommitRequest only.
- UWG is sole ink authority.

X3D_ALLOW_FINISH
- Safe final runtime answer/outcome can leave.
- No durable write occurs here.
- May reference committed artifact only after UWG receipt exists.

X3E_SAFE_ABSTAIN_CLARIFY
- The safe valid outcome is abstain, clarify, or explain bounded inability.
- This is a valid success when evidence/policy does not permit completion.
- No durable write.

DISPOSITION SELECTION ORDER
------------------------------------------------------------------------------------------------------------------------
1. If hard fail -> X3A unless human review is required and recovery is plausible -> X3B.
2. If human-required or material UNKNOWN -> X3B unless safe abstain is the policy-mandated outcome.
3. If write path active and all commit preconditions pass -> X3C.
4. If answer-only and allow preconditions pass -> X3D.
5. If safe abstain/clarify is the proper supported outcome -> X3E.
6. If no branch is safe -> X3A safe stop.

Do not:
- emit multiple X3 dispositions.
- silently fallback.
- mix allow + commit without explicit UWG receipt.
- skip X1 result materiality.
- route around HITL/L5/UWG.
