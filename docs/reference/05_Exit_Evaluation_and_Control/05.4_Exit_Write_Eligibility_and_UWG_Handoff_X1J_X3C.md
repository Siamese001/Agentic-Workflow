OBJECTIVE
------------------------------------------------------------------------------------------------------------------------
Implement X1J and X3C handoff construction.

This child answers one question only:
"Is the sealed result eligible to request a durable mutation, and if so, is the CommitRequest complete enough for UWG to decide?"

HARD BOUNDARY
------------------------------------------------------------------------------------------------------------------------
Exit does not write. Exit does not acquire write locks. Exit does not mutate L4. Exit does not perform rollback.

Exit may emit:
- write_eligibility_status
- CommitRequest
- UWG handoff packet

UWG decides:
- accept commit
- block commit
- hold commit
- rollback
- refresh read surfaces
- append durable audit ledger

X1J WRITE ELIGIBILITY OK?
------------------------------------------------------------------------------------------------------------------------
Applies when any of the following is present:
- StateDiff
- external action result that must be recorded
- durable memory update
- policy update candidate
- registry update candidate
- artifact publication
- cache promotion/invalidation
- retrieval surface refresh request
- customer-impacting change
- learning promotion request coming through future-run path

Checks:
- Proposed change is necessary, explicit, and within user/request scope.
- write_intent_class declared.
- StateDiff complete and bounded.
- Diff target surface is known to L4/UWG.
- Diff scope matches capability_token and sandbox_envelope.
- Blast radius classified.
- Rollback plan present where required.
- before_snapshot and after_candidate refs available.
- High-impact or irreversible action routed through HITL.
- X1A-F cleared.
- X1G cleared when commit path is active.
- X1H/I cleared.
- HITL receipt attached where required.
- L5 certification refs attached where required.
- Next hop is UWG only, not direct L4 write.

Outputs:
- write_eligibility_status
- write_intent_class
- target_state_surfaces[]
- blast_radius
- rollback_required
- rollback_status
- state_diff_status
- uwg_handoff_packet_id
- commit_path_blockers[]

Fail routes:
- WRITE_SCOPE_AMBIGUOUS
- WRITE_NOT_AUTHORIZED
- STATE_DIFF_MISSING
- STATE_DIFF_SCHEMA_INVALID
- ROLLBACK_MISSING
- BLAST_RADIUS_TOO_BROAD
- HIGH_IMPACT_NEEDS_HITL
- L5_CERTIFICATION_GAP
- DIRECT_L4_WRITE_ATTEMPT
- UWG_HANDOFF_INCOMPLETE

X3C EMISSION RULES
------------------------------------------------------------------------------------------------------------------------
Emit X3C only when:
- Mutation requested and authorized.
- X1A-F clear.
- X1G clear where commit path active.
- X1H clear.
- X1I clear or policy-allowed non-material WARN.
- X1J clear.
- HITL completed if required.
- CommitRequest complete.
- Next hop is UWG only.

Do not emit X3C when:
- StateDiff incomplete.
- StateDiff target unknown.
- Commit path reliability unknown and high impact.
- Replay is non-certifiable.
- Trace gap blocks forensic review.
- Direct write already occurred.
- L5 certification required but missing.
- HITL required but missing.
- Rollback required but missing.

UWG RESPONSE HANDLING
------------------------------------------------------------------------------------------------------------------------
Exit may receive later:
- UWGCommitReceipt
- UWGBlockedCommitReceipt
- UWGHeldCommitReceipt
- UWGRollbackReceipt

Exit may reference committed artifact only after UWGCommitReceipt exists.

If UWG rejects:
- Return safe message or X3A/X3B depending reason.
- Do not claim mutation happened.

If UWG holds:
- Return pending/review-safe response if policy allows.
- Do not claim mutation happened.

OTEL SPANS
------------------------------------------------------------------------------------------------------------------------

- exit.x3c.uwg_handoff_emit
- exit.uwg_response.receive

TEST REQUIREMENTS
------------------------------------------------------------------------------------------------------------------------
- Exit never writes directly to L4.
- StateDiff without before_ref fails X1J.
- Missing rollback plan fails when rollback required.
- High-impact mutation without HITL fails X1J.
- Missing L5 cert ref fails when policy requires it.
- X3C cannot emit with X1G UNKNOWN on high-impact commit.
- X3C CommitRequest next_hop must equal UWG_ONLY.
- Final response cannot reference committed artifact before UWG receipt.
