```

                        ↓          ↓          ↓          ↓          ↓
                    [Allocate]  [Foundation] [Explore]  [Select]  [Generate]
                    Resources    Consensus    Depth      Best      Response
```

---

## **STAGE 0: Initialization & Context Loading** 
**Purpose:** EL (Engagement Leader) receives tokens, analyzes complexity, allocates reasoning resources

The EL receives pre-encoded tokens from the embedding layer (each with 12,000-dimensional vectors), analyzes their semantic clustering to calculate a complexity score, then strategically allocates CoT consultants, ToT specialists, and SC reviewers based on domain count and token spread. Positional encoding is added, configuration parameters are locked, and the war room is prepared. Attention mechanisms remain OFF until Stage 1.

**Key Outputs:**
- **Resources Allocated:** [N] CoT consultants, [M] ToT specialists (reserved), [K] SC reviewers
- **Complexity Score:** Calculated from domain clustering (guides resource allocation)
- **Context Window:** Tokens seated with positional encoding (e.g., 846/1024 capacity)
- **Status:** All parameters locked, room sealed, attention ready to activate

---

## **STAGE 1: Foundation Consensus (Slides 1-2)**
**Purpose:** Establish shared understanding across all CoT paths through convergent reasoning

Q·K·V attention activates. The allocated CoT consultants (typically 3) begin querying input tokens through attention mechanisms, each developing their perspective on Slide 1 (initial problem decomposition), then converging on Slide 2 to establish a consensus foundation. Entropy collapses as paths align, creating the shared baseline for deeper exploration.

**Key Outputs:**
- **Consensus Foundation:** All CoT paths agree on core understanding (>75% alignment)
- **Entropy Reduction:** Initial entropy (e.g., 0.61) → Converged entropy (e.g., 0.34)
- **Persona Contributions:** Each consultant's perspective integrated into foundation
- **Reflexion Check:** Optional quality validation if consensus is weak

---

## **STAGE 2: Depth Development & Conditional Branching (Slides 3-N)**
**Purpose:** Explore implications from foundation, activate specialists if ambiguity detected

CoT consultants continue developing depth through slides. The EL continuously monitors attention entropy across all 16 heads. If ambiguity exceeds threshold (>0.75), ToT specialists activate to build decision trees in their domains (minimum depth=3). The war room operates in parallel: main consultants continue narrative while specialists explore branches. Paths may diverge significantly before reconverging with specialist insights integrated.

**Key Outputs:**
- **Depth Development:** 3-N slides of reasoning (3 or 7 paths depending on ToT activation)
- **ToT Activation:** 0-4 specialists triggered based on entropy spikes
- **Entropy Arc:** Controlled divergence → exploration → reconvergence
- **Specialist Integration:** Domain-specific decision trees merged into main narrative

---

## **STAGE 3: Path Selection & Convergence (Reflexion)**
**Purpose:** Select best content per slide position, validate through independent review

A voting matrix evaluates all path candidates (3 CoT + up to 4 ToT) for each slide position. The winning content for each slide is selected and assembled into a hybrid path. SC reviewers (typically 5) independently re-reason through the entire chain, providing critique. The EL orchestrates a Reflexion loop where feedback is integrated, refining the final recommendation.

**Key Outputs:**
- **Hybrid Path:** Best content selected from each slide across all paths
- **SC Validation:** Independent review panel agreement (target >80%)
- **Reflexion Refinements:** Critical feedback integrated (e.g., timeline buffers, reserves)
- **Final Confidence:** Post-reflexion confidence score (e.g., 0.92)

---

## **STAGE 4: Delivery Validation & Lock-In**
**Purpose:** Generate output tokens, validate quality gates, deliver final response

The hybrid reasoning path drives autoregressive token generation. Each new output token is generated by attending to all input tokens plus reasoning states. Temperature=0.0 ensures deterministic output. The EL validates quality gates (length, tone, accuracy, completeness) before approving delivery.

**Key Outputs:**
- **Generated Response:** 487 tokens (under 512 limit)
- **Quality Validation:** All gates passed (format, attribution, coherence)
- **Persona Attribution:** Clear mapping of which persona contributed what
- **Delivery Metrics:** Confidence scores, path composition, decision rationale
