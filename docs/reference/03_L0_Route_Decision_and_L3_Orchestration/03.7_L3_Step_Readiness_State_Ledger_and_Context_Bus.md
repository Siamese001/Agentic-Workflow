PHASE 2 READY NODE SELECTION
------------------------------------------------------------------------------------------------------------------------

select_next_ready_node(ledger, workflow_blueprint, context_bus) -> NodeReadinessDecision

Required checks:
- dependencies satisfied
- policy dependency cleared
- evidence dependency satisfied
- capability/sandbox requirement present
- join requirements complete
- budget remaining
- retry count below limit
- fallback chain not exhausted
- HITL pause not pending
- no hidden scope growth
- no direct write authority

PHASE 3 STEP CONTRACT EMISSION
------------------------------------------------------------------------------------------------------------------------

emit_step_contract(readiness_decision, ledger, context_bus) -> L3StepContract

Rules:
- Emit exactly one current bounded step.
- Include current node only.
- Include only refs the node is allowed to see.
- Attach capability/sandbox requirements, but do not mint broad authority.
- Attach PTC allowance only for L2_PTC_SANDBOX_STEP.
- Attach no durable commit authority.
- Parent span must be workflow span.
- Step contract must be replayable.

PHASE 4 RESULT MERGE
------------------------------------------------------------------------------------------------------------------------

ingest_step_result(step_result: StepResultIngest) -> HandoffMergeReceipt

Rules:
- Mark node done / failed / retry / paused / skipped.
- Attach reason_codes and receipts.
- Preserve L2 artifact lineage.
- Carry returned evidence refs only as data.
- Preserve contradiction flags.
- Do not silently collapse failed branch.
- Do not write to L4.
- Do not update learning state.

ACCEPTANCE TESTS
------------------------------------------------------------------------------------------------------------------------
- Node with unsatisfied dependency is not ready.
- Ready node emits exactly one step contract.
- Step contract for PTC is L2_PTC_SANDBOX_STEP and includes sandbox requirement.
- L3 does not call tool/model.
- L3 does not retrieve.
- L3 does not write durable state.
- Merge preserves branch lineage and contradictions.
- Ledger hash is deterministic.
