RULES
------------------------------------------------------------------------------------------------------------------------
Signal fusion:
- Weight by source reliability, evaluator reliability, sample size, severity, confidence, recency, reproducibility, user impact,
  and policy criticality.
- Do not promote popularity as correctness.
- Do not treat preferences as correctness without rubric.
- Preserve disagreement and uncertainty.

RCA:
- Identify first_bad_span when possible.
- Identify affected surface: route, cache, retrieval, rerank, graph, prompt, model, tool, policy, rubric, HITL, UWG, replay,
  evidence lineage, sandbox, provider.
- Build failure_chain rather than a vague diagnosis.
- "The model was bad" is not actionable RCA.
- UNKNOWN_ROOT_CAUSE is allowed, but blocks proposal admission until enough evidence exists.

Pattern synthesis:
- Cluster repeated failures, similar route misses, retrieval gaps, policy friction, tool misuse, prompt confusion, false cache hits,
  HITL disagreement, citation support failures, abstain/refusal drift, provider-specific failures.
- Distinguish one-off incident, local defect, systemic rule gap, eval gap, documentation gap, policy ambiguity,
  tool/provider drift, and data/index freshness issue.

TEST REQUIREMENTS
------------------------------------------------------------------------------------------------------------------------
Tests must fail if:
- raw traces feed RCA without CompletedEvalRecord.
- RCA packet lacks affected surface.
- root cause is vague with no hold reason.
- first_bad_span is invented when unavailable.
- disagreement/counterexamples are dropped.
- one-off incidents are marked systemic without sample support.
