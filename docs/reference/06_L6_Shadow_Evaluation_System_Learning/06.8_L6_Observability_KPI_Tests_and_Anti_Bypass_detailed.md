KPI BOARD
------------------------------------------------------------------------------------------------------------------------
- Trace-ingest freshness: newest ingested span age <= 10 minutes.
- Evidence field completeness: >= 99% required normalized fields present.
- Orphan artifact rate: <= 0.5% artifacts lack trace/run linkage.
- Observer-law violation count: 0 writes / live mutations from L6.
- Eval readiness coverage: >= 98% runs evaluable within 24h.
- Outcome eval coverage: >= 98% last-24h runs.
- Trajectory eval coverage: >= 98% non-RET executions graded.
- Governance eval coverage: 100% high-risk / write / HITL paths checked.
- Judge Unknown-budget compliance: >= 95%.
- Judge-human agreement freshness: latest calibration <= 7 days per rubric.
- Golden-set regression pass rate: >= 99% critical cases pass.
- RCA-to-proposal lead time: p95 incident close -> proposal <= 24h.
- Root-cause localization rate: >= 90% incidents have first_bad_span/class or explicit UNKNOWN hold.
- Proposal evidence completeness: 100% proposals link eval + RCA + evidence.
- Gauntlet false-promote rate: reverted promotions <= 1%.
- Eval freshness on write: 100% writes have fresh gating eval.
- UWG ink-path uniqueness: non-UWG writers detected = 0.
- Rollback reachability: 100% promotions have tested rollback handle.
- BUS U activation correctness: 100% updates activate only at future run_start.

FAILURE MODES AND CONTAINMENT
------------------------------------------------------------------------------------------------------------------------
- Stale ingest -> mark stale, block learning until refreshed.
- Orphan evidence -> hold, request telemetry repair, exclude from promotion.
- Eval gap -> block 6C/6D.
- Forced certainty -> calibration failure, block rubric use.
- Preference overfitting -> require rubric + SME calibration.
- RCA vagueness -> hold proposal until actionable surface is identified or UNKNOWN_ROOT_CAUSE is declared.
- False promote -> rollback, mark gauntlet regression, open RCA.
- Shadow writer -> freeze, sovereignty incident, require UWG/L4 audit.
- Stale eval on write -> UWG reject.
- Partial bypass -> reject unless ADR-scoped exception with narrowed blast radius.
- Current-run mutation -> fatal invariant breach.
- Rollback missing -> reject promotion.
- Cache contamination -> disable surface, purge cache via UWG-approved path, RCA.
- Rubric drift -> hold evals, recalibrate.
- Replay nonlocalization -> block promotion, improve instrumentation.

PACK-LEVEL TEST REQUIREMENTS
------------------------------------------------------------------------------------------------------------------------
Tests must fail if:
- L6 starts from an in-flight run.
- L6 mutates live runtime state.
- L6 writes to L4 directly.
- L6 publishes BUS U before UWG receipt.
- L6 RCA consumes raw traces without CompletedEvalRecord.
- L6 proposal lacks eval record.
- L6 proposal lacks RCA/pattern record.
- L6 proposal lacks rollback plan.
- L6 proposal lacks exact diff.
- L6 proposal bypasses gauntlet.
- L6 approval bypasses stale eval/calibration checks.
- L6 promotion has no content hash.
- L6 activation applies before next run_start.
- Unknown is coerced into PASS.
- Human preference becomes policy directly.
- Non-UWG writer is detected.
- Replay divergence cannot be localized but promotion proceeds.

ACCEPTANCE CRITERIA
------------------------------------------------------------------------------------------------------------------------
The L6 pack is accepted only when:
- All child surfaces emit deterministic receipts.
- Observer law is test-enforced.
- Eval-before-learning is test-enforced.
- Future-run-only activation is test-enforced.
- UWG sole-write path is test-enforced.
- Unknown and uncertainty are preserved.
