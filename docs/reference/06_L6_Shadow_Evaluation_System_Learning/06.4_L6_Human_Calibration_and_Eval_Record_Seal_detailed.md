CALIBRATION AND SEAL RULES
------------------------------------------------------------------------------------------------------------------------
- Each rubric must have calibration freshness within configured TTL.
- Stale rubric cannot support proposal admission without refresh or explicit hold.
- Rubrics must allow Unknown.
- Human agreement is tracked by task class and rubric.
- Reviewer override is calibration evidence, not live authority.
- Calibration may propose threshold/rubric updates, but does not commit them.
- CompletedEvalRecord must bind score vectors, rubric hashes, grader versions, evidence snapshots, uncertainty markers,
  and support rationale.
- 6C cannot consume anything not sealed here.

TEST REQUIREMENTS
------------------------------------------------------------------------------------------------------------------------
Tests must fail if:
- human preference directly changes policy/rubric.
- single reviewer override becomes promotion-ready without calibration.
- stale rubric is used for proposal admission.
- Unknown is erased during seal.
- completed eval record lacks evidence snapshot hash.
- 6C consumes unsealed eval record.
