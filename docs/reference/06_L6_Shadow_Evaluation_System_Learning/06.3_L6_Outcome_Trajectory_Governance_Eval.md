EVALUATION REQUIREMENTS
------------------------------------------------------------------------------------------------------------------------
Outcome eval must grade:
- task completion, correctness, groundedness, citation support, source coverage, evidence sufficiency, abstain correctness,
  refusal correctness, format/schema fit, user constraints, scope discipline, usefulness, artifact validity, unsupported inference risk.

Trajectory eval must detect:
- route thrash, silent fallback, tool misuse, tool overreach, hidden scope growth, unbounded loop, skipped C0 grounding,
  skipped prompt validation, premature answer, stale cache reuse, excessive model escalation, non-replayable behavior,
  unnecessary HITL, missing HITL.

Governance regression must check:
- guard became too loose, guard became too strict, eval no longer measures intended behavior, stale baseline,
  hidden policy mismatch, rubric rewarding wrong behavior, replay digest drift, UWG receipt drift.

Must allow:
- UNKNOWN, PARTIAL_SUPPORT, CONFLICTED_SUPPORT, NOT_ENOUGH_EVIDENCE.

Must not:
- force binary certainty, reward unsupported fluency, hide missing citations, count style as correctness, grade beyond evidence.

GRADER RULES
------------------------------------------------------------------------------------------------------------------------
- Code graders decide structural facts where possible.
- LLM judges handle semantic quality only when code cannot decide.
- Hybrid graders expose code vs judgment components.
- Unknown is valid and must not be coerced into pass.
- Judge context is isolated from graded agent output.
- Grader cannot be steered by the answer being graded.

TEST REQUIREMENTS
------------------------------------------------------------------------------------------------------------------------
Tests must fail if:
- 6B runs before EvalReadinessReceipt.
- Unknown uncertainty is converted to pass.
- Unsupported fluency receives correctness credit.
- Trajectory flags silently drop route/tool/prompt/retrieval skips.
- Governance regression omits policy_hash, rubric_hash, or replay digest references.
- Evaluation result is used as live Exit disposition.
