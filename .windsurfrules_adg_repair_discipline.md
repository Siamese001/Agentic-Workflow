# ADG Repair Discipline — Constitutional Rule

## MANDATORY: Graph-First Repair Protocol

**ALL code repairs MUST be derived from ADG dependency graph analysis.**

### Hard Gates (NEVER violate)

1. **No edit without ADG provenance**
   - Every file edit MUST answer:
     - Which ADG cluster? (cluster ID from `adg_failure_clusters.json`)
     - What is the root module? (from dependency chain)
     - Which scoped tests prove the fix? (from test coverage graph)
     - Why is this file in the blast radius? (from semantic graph edges)
   - If you cannot answer all four, the edit is FORBIDDEN.

2. **No full-suite runs before convergence**
   - `pytest tests/unit` is FORBIDDEN until ALL current ADG clusters are green.
   - Only scoped test runs are allowed: `pytest <cluster_test_files> -q`
   - Convergence = all scoped tests from current clusters pass.

3. **No symptom-based debugging**
   - FORBIDDEN: grep for missing imports, hunt for undefined variables, patch test files directly.
   - REQUIRED: Use ADG semantic graph to trace import edges, identify root definition nodes, compute blast radius.

4. **Repair only the dependency root**
   - Fix the ROOT module in the dependency chain, not downstream consumers.
   - Example: If `TESTS_DIR` is undefined in 5 files, fix the DEFINITION site, not all 5 call sites.
   - Use ADG edges to find the canonical definition node.

### Allowed ADG-Controlled Workflow

```
PHASE 5-6 Repair Loop:
1. Load adg_failure_clusters.json
2. For each cluster (ranked by priority):
   a. Extract root module from dependency chain
   b. Extract impacted test files from test coverage graph
   c. Use semantic graph to identify fix location (definition node, not call site)
   d. Apply minimal fix to root module only
   e. Rerun ONLY impacted tests from cluster
   f. If green → mark cluster complete, continue
   g. If red → analyze NEW failure, update dependency chain, repeat
3. When all clusters green → PHASE 7 (full suite validation)
```

### Forbidden Patterns

- ❌ Running `pytest tests/unit` before all clusters converge
- ❌ Editing files not in current cluster's blast radius
- ❌ Fixing call sites instead of definition sites
- ❌ Adding imports to test files without ADG justification
- ❌ Text-search debugging (`grep`, `find`, manual inspection)
- ❌ Patching multiple unrelated files in one repair cycle

### Required Artifacts

Every repair cycle MUST:
1. Read `artifacts/adg_failure_clusters.json` for cluster priority
2. Read `artifacts/adg_semantic_graph.json` for dependency chains
3. Read `artifacts/adg_test_surface_map.json` for test coverage
4. Write repair evidence to `artifacts/adg_repair_<cluster_id>.json`

### Enforcement

If Windsurf cannot answer these four questions for ANY edit:
1. Which ADG cluster?
2. What is the root module?
3. Which scoped tests?
4. Why is this in the blast radius?

Then the edit is OUT OF SCOPE and MUST NOT be made.

### Success Criteria

- ✅ All edits traceable to ADG cluster + dependency chain
- ✅ All test reruns scoped to cluster surface
- ✅ Full suite run ONLY after all clusters green
- ✅ Repair evidence artifacts written for each cluster
