# DoorDash Executive Summary - Benchmark Example

## Strategic Layer
**Core Thesis:** Transition from food delivery to local commerce platform achieving GAAP profitability through efficient growth.

**Financial Proof Points:**
- Q2 2025 Revenue: $3.3B (+25% YoY)
- GAAP Net Income: $285M (first profitable quarter)
- Insurance expense decreased as % of GOV (Gross Order Value)
- Operating margin expansion through logistics efficiency

## Technical Layer
**Key Technologies:**
1. **Gated Mixture-of-Experts (MoE) Architecture**
   - Deep learning models for ETA predictions
   - 20% improvement in delivery time accuracy
   - Deployed across logistics network

2. **Dot Autonomous Delivery Robot**
   - Sidewalk-compatible autonomous vehicle
   - Level 4 autonomy for last-mile delivery
   - Deployed in partnership with Serve Robotics

3. **Infrastructure Stack:**
   - Kubernetes orchestration for microservices
   - PyTorch for ML model training
   - Real-time routing optimization engine

**Implementation Details:**
The MoE architecture enables dynamic model selection based on delivery context (urban vs suburban, weather conditions, traffic patterns), reducing computational overhead while maintaining prediction accuracy. The Dot robot integrates LiDAR, computer vision, and path planning algorithms to navigate complex urban environments.
