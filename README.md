# Agentic-Workflow

[![50/50 Canon](https://img.shields.io/badge/Subatomic%20Canon-50%2F50%20Keys-brightgreen)](canon_validator.py)

## Overview

Agentic-Workflow is a production-grade framework for building and orchestrating AI agents with strict architectural governance.

## 50-Key Subatomic Canon

This repository enforces a **50-key validation canon** that ensures:
- Zero architectural debt
- Strict sovereign domain boundaries
- Clean code hygiene
- No stubs, placeholders, or temporary workarounds

Run the validator:
```bash
python canon_validator.py
```

## Architecture

- **Sovereign Domains**: Core architectural pillars with full canon enforcement
- **Light Canon**: Non-sovereign code with relaxed but still strict rules
- **Zero-Loss**: No code or functionality is lost during refactoring

## Quick Start

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run validation:
   ```bash
   python canon_validator.py
   ```

3. All 50 keys must pass for the repository to be considered valid.
