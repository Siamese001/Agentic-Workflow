# Archived Obsolete Tests

This directory holds test files that **fail at import time** because the modules
or symbols they reference no longer exist (or were never built — they were
written against a planned API that was redesigned or descoped).

## Why archived, not deleted

Each file documents the *intended* behavior of a planned component
(KillSwitch, NetworkEgressGuard, ConsensusValidator, the L4 enforcement suite,
etc.). Keeping them under version control preserves the design intent for
future reference if any of those components are revived.

## Why excluded from collection

`pytest.ini` adds `_archived_obsolete` to `norecursedirs` so this directory is
never walked by collection. They contribute zero coverage and are not run in
CI. The Windsurf / VS Code Test Explorer also skips them as a result, which
keeps the test tree clean.

## Layout

The relative path under this directory mirrors the original location under
`tests/`. For example:

    tests/agentic_core/L2_execution/enforcement/test_kill_switch.py
    →
    tests/_archived_obsolete/agentic_core/L2_execution/enforcement/test_kill_switch.py

## Restoring an archived test

If a previously-removed module is re-introduced and you want to revive its
tests:

1. Move the file back to its original location under `tests/`
2. Update imports/assertions to match the current shipped API
3. Run `python -m pytest <path>` and confirm it passes
4. Commit the move + fixes together
